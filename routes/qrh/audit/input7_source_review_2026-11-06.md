## 2. 定理与 Lean 的逐项对应

作者 v3 的印刷第 2 页 Theorem 1，对 Table 2 中的每一对参数给出：

\[
\forall x\in\mathbb R,\quad x\ge x_0\Longrightarrow
\exists p\text{ prime},\quad x(1-\Delta^{-1})<p\le x.
\]

Lean 定义为：

```lean
def CHLInterval (Δ X : ℝ) : Prop :=
  ∀ y : ℝ, X ≤ y →
    ∃ p : ℕ, p.Prime ∧ y * (1 - 1 / Δ) < (p : ℝ) ∧ (p : ℝ) ≤ y
```

这里 `X` 对应 `x₀`，`y` 只是对 `x` 的改名；素数以自然数及其实数嵌入表示。左端严格、右端非严格完全一致。Theorem 1 的陈述没有要求 `x` 为整数、没有上限、没有另附 RH 或 QRH 假设。论文证明内部的平滑函数与参数选择是作者建立该定理的工作，并不是遗漏在此定义外的使用条件。由右端闭区间转成最终相邻六次幂之间的开区间，属于项目自己的后续 Lean 推导，不是更改 CHL 原定理。

上述代码重放采用普通高精度实数运算和 SciPy 数值积分，部分常量在进入 `mpf` 前已是 Python 浮点数；没有建立有向舍入、积分尾部和全部运算的严格误差界。因此不能把正余量、辅助参数调整或 350 位设置称为新的严格证书，更不能据此删除 `CHLRows` 外部输入。若将来需要独立认证 CHL 数值层，应将这十二组见证参数固定，并对全部判据另做严格区间核验。

## 7. 六个参数舍入差异的严格 Arb 诊断

新增原创可重放脚本 [`check_chl_rounded_deltas.py`](check_chl_rounded_deltas.py)，结果为 [`chl_rounded_deltas_arb_2026-11-06.json`](chl_rounded_deltas_arb_2026-11-06.json)。在 Python 3.12.10、`python-flint 0.9.0`、Arb 精度 **256 位二进制**下，仅计算

\[
\Delta(m,\delta,a)=
\left(1-\frac{1+\delta a}
 {\exp(\delta/m)\bigl(1+\delta(1-a)\bigr)}\right)^{-1}.
\]

`m, δ, a` 均直接取 v3 第 12 页的印刷数值；有限十进制字符串先转换成精确有理数，再交给 Arb 包含，整个诊断没有使用 Python 浮点输入。脚本先以区间下端确认分母严格为正，然后检查 `生成的 Δ − 表中整数 Δ` 的整个区间是否严格位于零的一侧。

十二行比较全部得到确定结果：

- **严格低于表值：**`log x₀ = 50, 60, 75, 90, 105, 135`。
- **严格高于表值：**`log x₀ = log(4·10¹⁸), 43, 46, 55, 120, 150`。

JSON 同时保存每行生成 Δ 和差值的区间、精确的二进制有理端点、输入有理数、依赖版本与脚本散列；区间端点按 `mantissa·2^exponent` 表示。重放命令为：

```text
python routes/qrh/audit/check_chl_rounded_deltas.py --output routes/qrh/audit/chl_rounded_deltas_arb_2026-11-06.json
```

这是依赖 FLINT/Arb 正确性的严格数值区间诊断，**不是 Lean 内核证明**。它确认了公开的舍入辅助参数无法原样生成六个精确表值，却不排除更精确或邻近参数可以实现它们；第 6 节给出了这方面的非严格数值佐证。它没有认证 `constraint1`、积分、CHL 定理或未取得的正式勘误表，也没有改变任何 Lean 假设。
