# 平滑显式公式的独立审阅

日期：2026-11-06。审阅者：独立子代理 `k4_sources`。

范围：审视拟用于 QRH(7/8) 下 k=4、k=3 探索的数学归约及可改进处。接受所有非平凡零点的实部不超过 7/8 作为本项目输入；没有重新审查 OpenAI 的证明，没有运行最终数值证书，也没有修改 `legendre_k67`。

## 1. 归一化与显式公式

设 x>1、h>0、Y=x+h，I_M=∫_0^1 φ_M(u)du，其中 φ_M(u)=u^M(1-u)^M，区间外零延拓。令 F(t)=φ_M((t-x)/h)，A=∫F(t)dt=hI_M。M 为至少 2 的整数。

适当平滑版本的 von Mangoldt 显式公式给出

    Σ_m Λ(m)F(m)
      = A − Σ_ρ ∫_x^Y F(t)t^(ρ−1)dt
          − ∫_x^Y F(t)/[t(t²−1)]dt.

F 在端点为零，因而素数幂恰落在端点时不会引入半权约定；常数项的分部积分边界也消失。这里必须从允许当前正则性的积分显式公式推出，不能只对逐点、条件收敛的零点级数形式微分。

对 M≥2，F 为 C¹，F′ 绝对连续，F″ 可积；零点变换至少按 |γ|^−2 衰减，结合 N(T)=O(T log T)，保证零点和绝对收敛。M=2 可以使用，不能误要求其零延拓属于 C²。

平凡零点项归一化后满足

    0 ≤ A^−1 ∫ F(t)/[t(t²−1)]dt ≤ 1/[x(x²−1)].

## 2. 所拟 Mellin 包络合法

设 q=Y/h、R_j=||φ_M^(j)||₁/I_M，R_0=1。对 0≤j≤M，端点导数消失，分部积分得到

    |∫ F(t)t^(ρ−1)dt|/A
      ≤ x^(β−1) R_j(q/|γ|)^j.

理由是分母 |ρ(ρ+1)…(ρ+j−1)|≥|γ|^j，且对 0<β<1，t^(β+j−1)≤Y^j x^(β−1)。因此

    g(t)=min_{0≤j≤M} R_j(q/t)^j

是合法、连续、非增的包络。相交点只有折角而没有跳跃；可用 −dg 的 Stieltjes 测度，也可按活跃幂段积分 −g′。g 在小高度为 1，最终为 t^−M 量级。

## 3. 零点实部积分与更紧的对称版本

N(T) 计正高度、全部实部、含重数的零点。N(σ,T) 计 β≥σ 的正高度零点。端点用 > 或 ≥ 对 σ 积分没有影响。

最初拟定的

    Φ(T)=x^(−1/2)N(T)
          + L∫_(1/2)^(7/8) x^(σ−1)N(σ,T)dσ,  L=log x,

是 Σ_(0<γ≤T) x^(β−1) 的合法上界：β<1/2 的零点用 x^−1/2 放大处理。正负高度共轭给出总误差上界 2∫ Φ(T)(−dg(T))。不得遗漏这个 2，也不得在 N(T) 已计双边高度时再次乘 2。

**推荐立即采用严格更紧的对称版本：**同一正高度上的零点按 β↔1−β 配对，可以精确写成

    Φ_sym(T)=x^(−1/2)N(T)
          + L∫_(1/2)^(7/8) [x^(σ−1)−x^(−σ)]N(σ,T)dσ.

这是实际加权累计零点和的恒等式，而不仅是上界。方括号对 σ>1/2 非负，因此可安全代入任何合法密度上界。这利用了左侧配对零点低于 x^−1/2 的节省，不是两个独立上界的相减。与原版本相比，近临界线的积分可能明显下降。

离散 σ 单元 [a,b] 可使用正系数

    C(a,b)=x^(b−1)+x^(−b)−x^(a−1)−x^(−a) ≥0

并以上界 D(a,T) 乘 C(a,b)，因为 N(σ,T)≤N(a,T)。它提供容易严格化的上和；先浮点 Gauss 求积探索、再以这种正系数分段或区间求积认证，逻辑清楚。

## 4. 有限 RH 高度与密度输入

采用保守的 H=3×10^12。对 T≤H、σ>1/2，N(σ,T)=0。T>H 时，Chourasiya–Simonič v1 Corollary 1、Table 1 对各闭区间 [σ₁,σ₂] 给出

    N(σ,T) ≤ B₁ T^[3(1−σ)/(2−σ)](log T)^3
               + B₂(log T)^2 + B₃ log T.

输入必须逐行使用对应区间，不能把某行较小常数推广到整个 [.5,.875]。该原文计 β≥σ、0<γ≤T，含重数；它不是只计 RH 右侧已知出现的零点。

原始来源：[Chourasiya–Simonič, arXiv:2507.15184v1, Corollary 1 与 Table 1](https://arxiv.org/html/2507.15184v1)。这是引用已声明的定理；本次没有重做其上游常数证明。

额外的安全帽可取

    N(σ,T) ≤ (N(T)−N(H))/2,  σ>1/2, T>H,

因 RH 高度以下没有右侧零点，且右侧零点有不同的左侧配对。实现时应使用 N(T) 的上界与 N(H) 的严格下界或精确值；不能减去 N(H) 的上界。若不需要此项，可先保持全 N(T) 基底和完整低零点积分，避免漏计。

对 σ>1/2 的零点个数上界，还可先将多个合法密度界、半数高计数帽取点态最小值。即使选出的上界在参数分界处不平滑，仍可在非负的 −dg 积分中使用。**不能由 N≤D 推出 dN≤D′dT。**应先用 Stieltjes 分部积分，再替换累计计数。

H 处的累计上界可能向上跳跃。上界在 T=H 单点的选择不影响连续 −g′ 积分，但积分从 H 开始的正长度不得因向上舍入丢掉。保留区间端点，或明确补偿整个舍入误差。

## 5. 低零点、素数幂与严格区间

低零点必须通过 g 的完整积分计入。N(H)g(H) 并不等于 Σ_(γ≤H)g(γ)，也不能在 g 于低高度显著变化时充当其上界。用全 N(T) 的基底积分并在 H 以下令额外密度积分为零，逻辑上可行。

若 P(Y)=ψ(Y)−θ(Y) 的已知上界有效，则非素数素数幂的加权贡献至多

    max φ_M · P(Y),

故归一化扣除为

    (max φ_M/I_M) · P(Y)/h.

这是安全但偏松的全局扣除。必须在 Y 而不是 x 检查 P 的适用下限；不得拿 ψ−θ 的渐近式当显式界。可改进为局部素数幂上界，但对 k=4 的大变量区间，P(Y)/h 约为 x^−1/4，通常不是主要瓶颈。

当完整误差（非平凡零点、平凡零点、素数幂扣除）严格小于 1 时，存在 F(p)>0 的素数 p，因此 x<p<Y。端点严格性由 F 的支撑直接保证。

## 6. 可立即添加的更高一阶尾部包络

虽然 φ_M 零延拓通常不具备 M+1 阶普通可积导数，但 φ_M^(M) 有界变差。再作一次 Stieltjes 分部积分得到

    g(t) ≤ C_(M+1)(q/t)^(M+1),
    C_(M+1) = TV(φ_M^(M) 零延拓)/I_M
            = [∫_0^1 |φ_M^(M+1)(u)|du + 2 M!]/I_M.

两端各有一个大小 M! 的跳跃，**2M! 不能省略**。把这一项加入现有 min 包络不会使任何高度的估计变差，并让最终尾部多衰减一阶。

M=2 的独立精确校验值为

    I_2=1/30,
    max φ_2/I_2=15/8,
    R_1=15/4,
    R_2=40/√3,
    C_3=300.

因此可取

    g(t)=min(1, (15/4)q/t, (40/√3)(q/t)^2, 300(q/t)^3).

这一扩展需要在最终证明中列出有界变差分部积分引理；不能把它表述成原来普通分部积分条件已经自动允许 j=M+1。

## 7. 其他核与工作优先级

优先级建议：

1. 采用对称 layer-cake 系数；逐行使用新密度常数；加入合法的半数高计数帽。
2. 在相同 φ_M 核上加入 M+1 阶有界变差尾界，比较 M=2、3 等少数权。
3. 分别报告低零点、各 σ 段、H 以上尾部及素数幂扣除，确定失败主要来自哪一段。
4. 只有当现有正余量仍不足时，再研究 log 坐标 B-spline 或平顶核，避免先增加大量核参数。

一个可研究的替代族是 log 坐标中 r 个均匀密度的卷积，支撑长度 ε=log(Y/x)、中心 c=√(xY)。其 Mellin 变换可以用 [sinh(ρε/(2r))/(ρε/(2r))]^r 明写。对 Γ=|γ|，一个分离变量的包络是

    c^(β−1) min(1,[coth(ε/(2r))/Γ]^r),

归一化分母使用对应变换在 1 的值。它允许显式处理更多振荡，但粗略绝对值包络不保证胜过 β 多项式权；应先做同输入对照。若使用真实 sinc 振荡，核不再单调，不能原样套用只需要累计零点数的 −dg 正测度论证，须用单调上包络或分段变差控制。

## 8. 数值阶段的结论边界

Jacobi 根或导数范数的浮点计算、Gauss 求积、有限网格取样都适合探索，不构成区间证书。须明确分开：候选参数、点值正余量、整段严格上界、无限尾部单调论证。

认证可以在高度区间 [u,v] 取合法累计计数上界 D(v)，乘精确非负权 g(u)−g(v)；σ 方向采用第 3 节的正系数上和。必要时自适应细分，最后解析控制无限尾部。这比对带符号导数或不保守 Gauss 误差直接作结论更容易审计。

本审阅支持上述框架作为合法的探索起点，指出了可严格改进的两项结构；它不宣称 k=4 或 k=3 的全范围证明已完成。

### 弱零点总数界的补充依据

代码采用 N(t)≤t log t/(2π)，并检查 t≥64。可由 FKS Lemma 2.1、Remark 2.2 引述的 Rosser 界直接证明：

    N(t) ≤ t/(2π) log[t/(2πe)] + 7/8
             + .137 log t + .443 log log t + 1.588.

目标上界减右端的差为

    D(t)=t(log(2π)+1)/(2π)−7/8
           −.137 log t−.443 log log t−1.588.

D(64)≈25.2422>0，且 t≥64 时 D′(t)≥D′(64)≈.447857>0，故简化界成立。最终证书宜将这两个初等常数比较用有理/区间不等式固定下来，而不是只留下“checked”注释。
