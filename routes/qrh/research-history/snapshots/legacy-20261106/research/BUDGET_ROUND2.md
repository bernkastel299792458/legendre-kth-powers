# 第二轮：中段误差预算与敏感性

日期：2026-11-06。本文件分析现有充分条件的损失，不是实际素数误差或零点数量的测量。数值等级均为 **EXPLORATORY**。

复算：`python -X utf8 code/midrange_budget.py`。原始二维表为 `results/midrange_budget_round2.csv`，汇总及代码散列为同名 JSON。新实现按实部和高度积分参数分箱，与旧 `smooth_scan.py` 的 CS v2 高阶求积交叉比较；所列点最大相对差约 8×10^-8。

## 1. 最右一条带很重要，但不是全部问题

固定 k=4、M=2、L=120，CS v2 输入给出总上界约 2957.51057；非密度项总计仅约 4.6×10^-10。

| 实部积分条带 | 密度层积分中的占比 |
|---|---:|
| [0.84375,0.875] | 77.4741% |
| [0.8125,0.84375] | 18.0030% |
| [0.78125,0.8125] | 3.7171% |
| [0.75,0.78125] | 0.6854% |
| [0.71875,0.75] | 0.1122% |

下表把某阈值以上的整个**层积分项**人为置零，仅作预算诊断：

| 假想删除的层积分 | 剩下的密度上界表达式 |
|---|---:|
| σ≥0.84375 | 666.2061 |
| σ≥0.8125 | 133.7645 |
| σ≥0.78125 | 23.8317 |
| σ≥0.75 | 3.5610 |
| σ≥0.71875 | 0.2439 |

因此，若其他部分沿用本式，只针对最右一行改善，即使把该行彻底抹掉也不能通过。后一轮显式密度或加权估计应该同时考虑约 0.72 至 0.875，而不应只盯住 7/8 端点。这不是任何方法必须在整个区间改善的必要性定理。

这些条带是 layer-cake 表达式的积分变量。改变真实零点的位置会同时改变多个累计计数；不能把本表当成各实部条带内实际零点贡献的精确分解。

## 2. 高度积分预算

仍在 L=120、M=2，下表按 `2∫Φ(t)(−dg(t))` 的高度参数分箱：

| 高度积分参数 t | 密度积分占比 |
|---|---:|
| [H,2H] | 0 |
| [2H,10H] | 73.9216% |
| [10H,100H] | 25.9934% |
| [100H,10^4 H] | 0.0851% |

第一项为零，是因为旧核在这一段仍为常数，`−dg=0`。**这不意味着 H 到 2H 的零点没有影响**：其计数仍包含在后续每个 Φ(t) 中。这是 Stieltjes 积分的分解，不是零点和按 γ 分组的分解。

L=110 时 82.69% 的积分预算在 [H,2H]，17.02% 在 [2H,10H]；L=150 时主要预算已移至 [100H,10^8 H]。故只改良紧邻 H 的极窄局部计数，无法自动覆盖全部 L 中段。

## 3. 更强假设的敏感性实验

下面仅问：若把某个输入换成更强假设，同一数值充分条件何时到达 δ=0.9？**这些假设没有被证明，没有进入任何证书，也不是建议直接开展如此规模的零点核验。**

固定 M=2，假想把全局实部上限 7/8 下调，数值阈值为：

| L | 本公式达到 δ≈0.9 时的假想 β 上限 |
|---:|---:|
| 110 | 约0.7418 |
| 120 | 约0.7310 |
| 130 | 约0.7404 |
| 150 | 约0.7626 |

这说明简单将 7/8 微调一点，并不自然解决当前损失；它不证明这些上限是素数结论所必需。阈值末位有求积敏感性：独立加密后 L110 的根约为0.7418054，与初次根相差约1.36×10^-6，因此表格只保留四位小数作为尺度判断。

保持 β≤7/8，假想延长有限 RH 核验高度，并从 M=2,4,8,16 中选择达到 δ≈0.9 所需高度最小者，得到：

| L | 所试最佳 M | 假想 RH 高度 / 当前 H |
|---:|---:|---:|
| 110 | 8 | 3.284 |
| 120 | 8 | 38.897 |
| 130 | 8 | 460.032 |
| 150 | 8 | 63847.925 |

这条敏感性曲线说明“稍微扩大有限核验”不是整个缺口的低成本替代方案。每行都是单点实验；它既不认证相邻 L，也不提供最优性证明。

## 4. 对研究顺序的修正

优先寻找在有效高度范围内、对多个实部层同时有用的密度或加权零点估计。仅提高求积精度、改良素数幂扣除、截断更高尾部或改善最右一行常数，都不是足够的独立解决方案。与这一预算表配套的实际新密度试验见 `DENSITY_ROUND2.md`。
