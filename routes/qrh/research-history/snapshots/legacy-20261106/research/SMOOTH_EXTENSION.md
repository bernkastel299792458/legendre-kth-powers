# k=4 平滑证书延伸至 log x=375

日期：2026-11-06。结论条件于 QRH(7/8)，即所有非平凡 ζ 零点满足 \(\beta\le7/8\)，以及下述明确文献输入。

新证书以 32 个闭单元完整覆盖

\[
375\le L=\log x\le400,
\]

并对其中每个实数 \(x\) 证明开区间 \((x,x+4x^{3/4})\) 含素数。最大严格有理上界出现在 \([376,376.5]\)：

\[
\Delta\le\frac{997001584162892542329211}{10^{24}}
=0.997001584162892542329211<1.
\]

这是连续区间的 Arb 上和证书，不是离散采样，也不是形式化证明。它只延伸此前的平滑证书；没有证明 QRH，也没有闭合低于 375 的全部范围。

## 1. 固定依赖和适用域

代码：`code/certify_smooth_extension.py`。结果：`results/smooth_extension_certificate.json`。旧 `certify_smooth_segment.py`、旧说明和旧证书均未修改。

新脚本只读加载固定散列的旧脚本，复用有理数转 Arb、核函数、实部正矩形上界与累计密度函数。它不调用旧脚本的写入入口。原 `certify_cell` 的范围保护为 \([400,700]\)，新脚本另写允许 \([375,400]\) 的单元封装，保留相同数学公式，并重新逐单元核查条件；这不是直接删除旧范围保护而假定证明自动成立。

文献输入固定为 Chourasiya–Simonič，[arXiv:2507.15184v2](https://arxiv.org/html/2507.15184v2)，Corollary 1、Table 1 前 12 行和式 (11)。对于 \(T\ge H=3\cdot10^{12}\)、每行对应的闭实部区间，采用

\[
N(\sigma,T)\le cT^{p(\sigma)}(\log T)^{2+p(\sigma)}
+d(\log T)^2+e\log T,\qquad
p(\sigma)=\frac{3(1-\sigma)}{2-\sigma}.
\]

这里的对数幂是固定 v2 的 \(2+p(\sigma)\)。12 行常数复制在旧模块及新 JSON 中，并在验证时逐项核对；未使用 FKS 表。式 (11) 放宽为 \(N(T)\le T\log T\)，也只在 \(T\ge H\) 使用。

旧证明中平滑显式公式、零延拓的有界变差核、逐零点包络、layer-cake、正高度上和及素数幂扣除，实际只要求 \(a>0\)、支撑位于 \(x>1\) 与所调用的计数估计高度合法。其推导没有依赖数值阈值 400。以下逐项说明本次向下延伸仍满足条件。

* \(L\ge375>0\)，故 \(x>1\)、\(Y=x+4x^{3/4}>2\)，显式公式和平凡零点、素数幂界仍适用。
* 所有 \(\sigma\) 单元都在 \([1/2,7/8]\) 内，且完全包含于一条固定源表行。新分母 4096、8192、16384 均为 32 的倍数。
* 每个单元先认证起始 log-height \(u_0>\log H\) 且 \(g(e^{u_0})=1\)。32 个单元中的最小 \(u_0=2999/32=93.71875\)，远高于 \(\log H\)。因此核开始下降时及全部后续高度均处于文献适用域。
* 结束高度逐单元认证已经进入三次幂核段；无穷尾部使用完整累计计数，仍含低零点的残余权重。
* 所有核质量差均由 Arb 认证非负；每个闭单元的总扣除都严格小于 1。结论不依赖在 L 上猜测数值函数单调。

上述检查不重新证明 CS 作者的上游常数优化；接受已陈述的文献结果是明确的依赖。

## 2. 统一包络与正上和

仍取零延拓的 \(\phi(v)=v^2(1-v)^2\)、\(I=1/30\)、\(h=4x^{3/4}\)。核为

\[
g_q(t)=\min\{1,(15/4)q/t,24(q/t)^2,300(q/t)^3\},
\qquad q(L)=1+e^{L/4}/4.
\]

第三阶常数 300 包含零延拓的两个端点跳跃，不能仅取区间内三阶导数。对整个 \([a,b]\) 先逐零点作包络

\[
e^{(\beta-1)L}g_{q(L)}(|\gamma|)
\le e^{(\beta-1)a}g_{q_b}(|\gamma|),\qquad q_b=q(b).
\]

随后定义 \(A_a(T)=\sum_{0<\gamma\le T}e^{(\beta-1)a}\)，再作 Stieltjes 积分。其累计上界为

\[
A_a(T)\le e^{-a/2}N(T)
+a\int_{1/2}^{7/8}e^{(\sigma-1)a}N(\sigma,T)\,d\sigma.
\]

实部单元 \([s_0,s_1]\) 上用正矩形上界

\[
a(s_1-s_0)e^{(s_1-1)a}
\left[ce^{p(s_0)u}u^{2+p(s_0)}+du^2+eu\right],\quad u=\log T.
\]

把基底和这些项相加记为 \(\Phi_a(e^u)\)。正 log-height 上和为

\[
Z_{a,b}^{\mathrm{finite}}
=2\sum_i\Phi_a(e^{u_{i+1}})
\left[g_{q_b}(e^{u_i})-g_{q_b}(e^{u_{i+1}})\right].
\]

这里用实际累计计数的单调性和正测度；没有比较不同 L 下的 \(-dg\) 测度。任一网格跨越核的活跃段分界仍合法，因为使用的是精确核质量差。

在最终 log-height \(U\) 后，剩余 Stieltjes 积分满足

\[
Z_{a,b}^{\mathrm{tail}}
\le1800q_b^3e^{-a/8-2U}(U/2+1/4).
\]

此外令 \(\varepsilon=4e^{-a/4}\)，采用

\[
P_{a,b}=\frac{15}{8}\frac{\sqrt{1+\varepsilon}
[b+\log(1+\varepsilon)]^2}{8\log2}e^{-a/4},
\qquad V_a=\frac{e^{-3a}}{1-e^{-2a}}.
\]

证书验证 \(\Delta=Z^{\mathrm{finite}}+Z^{\mathrm{tail}}+P+V<1\)。由平滑显式公式可知正素数权重非零。核在两个端点为零，因此得到的素数严格位于 \((x,x+h)\)。特别地，\(x=n^4\) 时 \(x+h=n^4+4n^3<(n+1)^4\)。关于显式公式交换积分的正当性及核常数的完整论证，见固定依赖 `research/SMOOTH_CERTIFICATE.md`。

## 3. 固定分段网格与结果

全部端点、间距和最终上界使用精确有理数；文献中的有限小数直接传入 Arb，不先转换为二进制浮点数。实际运算为 160-bit Arb，Python 3.12.10，python-flint 0.9.0。

| L 范围 | L 单元宽度 | 实部间距 | log-height 间距 | L 单元数 |
|---|---:|---:|---:|---:|
| [375,376] | 1/4 | 1/16384 | 1/32 | 4 |
| [376,380] | 1/2 | 1/8192 | 1/32 | 8 |
| [380,400] | 1 | 1/4096 | 1/16 | 20 |

共 32 个闭 L 单元、39280 个高度单元。所有 L 端点依次精确相接，没有空隙；各段分别认证，无需把不同网格的上界作插值。生成用时约 124.3 秒，运行耗时受并行任务影响。

首单元 \([375,375.25]\) 得到

\[
\Delta\le990664548746360122910817/10^{24}.
\]

最坏单元位于网格切换后的 \([376,376.5]\)，其原始球为
`[0.9970015841628925423292107554979372945442 +/- 9.59e-42]`，向外取整为本说明开头的有理上界。

预先探测中，\([375,375.25]\) 用较粗 \(1/8192\) 实部、\(1/32\) 高度网格得到约 1.00918，不能认证；仅细化实部网格到 \(1/16384\) 即通过。另一次 \([375,375.125]\)、\(1/16384\times1/64\) 探测得到约 0.97626，但无需采用更昂贵的统一细网格。没有向 374 附近作极限搜索。某个网格未通过只说明该上界不够，不构成数学不可能性证据。

## 4. 复算方式与边界

从 `Legendre_k8` 目录运行默认三档网格生成：

```powershell
python code/certify_smooth_extension.py
```

全量只读验证，不重写 JSON：

```powershell
python code/certify_smooth_extension.py --verify
python code/certify_smooth_extension.py --verify results/smooth_extension_certificate.json
```

`verify_certificate(path=OUTPUT)` 核对自身和依赖文件的 SHA256、固定源版本和常数、核参数、精确首尾与连续覆盖，然后按保存的每单元网格和精度重新计算所有单元，要求复算的向外有理上界不超过保存值且严格小于 1。保存的浮点显示值和成功标记均不作为证明依据。`--single` 也只读，例如

```powershell
python code/certify_smooth_extension.py --single 375 1501/4 --sigma-denominator 16384 --height-denominator 32 --precision 256
```

已经实际完成一次全量只读 `--verify`，返回 `VERIFIED`，32 个单元全部通过，耗时约 118.7 秒，复核前后 JSON 的 SHA256 相同。另对内存中的证书副本制造相邻单元覆盖缺口，或把源版本改为 v1，验证器均明确拒绝；这两项负向检查未写入文件。

另外用未导入新旧证书模块的独立 384-bit 实现，按活跃区间分别计算核，把密度幂因子写成 \(e^{pu}e^{(2+p)\log u}\)，复算最坏单元 \([376,376.5]\)，得到

\[
0.9970015841628925423292107554979372945442095854350818405125362055777612627148378759426627230012389063
\]

的 Arb 包围球，半径不超过显示的 \(2.03\cdot10^{-101}\)，且严格小于保存的有理上界。独立表达式复算仅针对这个最坏单元；全量 `--verify` 使用同一个实现，应区分二者的独立程度。

与旧平滑 \([400,700]\) 和 CS 尾部 \([700,\infty)\) 拼接后，当前这些组件给出的条件连续大范围起点降为 \(\log x=375\)。对四次幂而言为 \(\log n\ge375/4=93.75\)。本证书不负责已核验小范围与 375 之间的空缺，也不声称已经证明全体 n 的四次幂猜想。
