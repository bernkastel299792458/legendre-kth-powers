在接受下述 CHL 区间定理和 Sorenson–Webster 有限基素性判定结果的前提下，已通过整数计算和 256 位 Arb 区间运算验证：对每个整数

\[
1\le n\le 767543999996,
\]

均存在素数

\[
n^4<p<n^4+4n^3<(n+1)^4.
\]

这覆盖了所有满足 \(4\log n\le 5473/50=109.46\) 的正整数 \(n\)。其对应底数最大值为 \(766422943598\)，向内取整后仍有重叠余量。实际整数覆盖终点对应

## CHL 到四次幂短区间的精确归约

设 \(x=n^4\)、\(h=4n^3\)、\(y=x+h\)。使用较强而方便的条件 \(x\ge x_0\)，即可保证 \(y\ge x_0\)。若

\[
n\le4(\Delta-1),
\]

则

\[
y(1-1/\Delta)\ge x
\quad\Longleftrightarrow\quad
(\Delta-1)h\ge x.
\]

CHL 因而给出 \(x<p\le y\)。对所有使用 CHL 的 \(n\ge44722\)，\(y=n^3(n+4)\) 是合数，故实际上 \(p<y\)。又

\[
(n+1)^4-y=6n^2+4n+1>0,
\]

所以所得素数严格位于所需的开区间。

因此每行提供整数区间

\[
\left\lceil x_0^{1/4}\right\rceil
\le n\le
\left\lfloor4(\Delta-1)\right\rfloor.
\]

所有 \(\Delta\) 的十进制展示值均由 `Fraction` 解析成精确有理数；本表中它们恰好都是整数。下端阈值使用 Arb 包围 \(\exp((\log x_0)/4)\)，确定唯一整数上下邻点，并另以 \(4\log n\) 检查阈值两侧。首行直接用整数四次幂比较。

## \(1\le n\le44721\) 的实际素数见证

精确整数比较给出

\[
44721^4<4\cdot10^{18}<44722^4.
\]

程序已为这 44,721 个整数逐一搜索 \((n^4,n^4+4n^3)\) 内的素数，保存每一个见证 \(p_n\)，并从保存的 JSON 重新读取验证。没有随机素性测试，也没有把 `sympy.isprime` 或未标注的 probable-prime 输出当作证明。

搜索器使用迭代平方实现强 Miller–Rabin 检验；独立检查函数直接计算定义中的模幂，不调用搜索器的素性函数。两者共用上述已发表的有限基界，因而这里的“独立”是实现层面的交叉检查，不是重新证明该界。每个见证都满足 \(p_n<2^{64}<B\)，所有区间关系均以整数严格比较。

## 复现与实际验收

环境：Python 3.12.10、python-flint 0.9.0，Arb 精度 256 bits。只使用 Python 标准库与 python-flint。

在 `D:\UGit\AI4Math` 下执行：

```powershell
python Legendre_k8\code\certify_lower_range.py --build
python Legendre_k8\code\certify_lower_range.py --verify
```

`--build` 重新搜索全部见证、写入本证书，然后从磁盘重新读入核验。`--verify` 只读证书并重新计算所有数学断言，不生成任何证书或改动其他项目。代码拒绝在 Miller–Rabin 严格阈值之外给出判定；证书缺失见证、改变端点、改变所用基或超出范围均会失败。

本次已实际完成生成后的全量检查，并在另一个 Python 进程再次执行只读全量检查，返回 `verified: true`。后一次检查耗时约 7.8 秒；时间只作环境记录，不是证明输入。另在内存中把首个见证改成合数 4，并同步重算哈希，检查器仍在素性环节明确拒绝；原证书未被修改。

后续解析路线可使用向内端点 \(L=109.46\) 作为重叠接点，但仍需明确证明其余所有 \(L\) 或其对应整数底数的覆盖。这里未完成 CHL 上游定理的独立审计、每个素数的 Pocklington 证书或完整 Lean 形式化；这些边界不应被 `verified: true` 掩盖。
