# L=120 附近：非负局部核能改善多少

日期：2026-11-06。性质：**方法诊断，不是中段证明或不可能性定理。** 这里给出一个严格的单零点变换引理，以及用 Arb 复算的尺度比较。密度上界的数值不被解释成实际零点数。

**版本更新：第 1、4 节的 CS 数值保留 v1 历史。当前采用 CS v2 时，同点探索值已从约 25638 降为约 2958；第 7 节给出更新后的密度规模。旧文中的“约四千倍”仅属于 v1，不能作为 v2 的数值结论。单零点相位引理与版本无关。**

## 1. 旧 v1 实验的失败位置

`results/smooth_k4_first.json` 中 `k=4,L=120,M=2` 的探索结果为

```text
delta          = 25638.376371424805
density_layers = 25638.376371424347
baseline       = 1.9506171721825885e-12
height_tail    = 8.974348020410693e-28
prime_powers   = 4.5563162349342344e-10
```

这个旧版本点的失败几乎完全来自有限 RH 高度以上、临界线右侧的密度积分项。提高最终无限高度尾部的积分截断、优化素数幂扣除，不能消除这里四个数量级的缺口；v2 的较小缺口见第 7 节。这个 `delta` 是探索实现计算的误差**上界表达式**，不是实际素数计数误差；浮点值也还不是严格区间认证。

## 2. 对任意非负核成立的单零点下界

设 \(x>1\)、\(h>0\)、\(y=x+h\)，\(F\ge0\) 可积、支持于 \([x,y]\)，且

\[
A=\int_x^y F(t)\,dt>0,
\qquad
\widehat F(s)=\int_x^y F(t)t^{s-1}\,dt.
\]

若沿用实验记号，则 \(A=hI\)。令 \(\ell=\log(y/x)\)。对 \(0<\beta\le1\)、\(\gamma\ge0\)，只要 \(\gamma\ell\le\pi\)，就有

\[
\boxed{\quad
\frac{|\widehat F(\beta+i\gamma)|}{A}
\ge y^{\beta-1}\cos\frac{\gamma\ell}{2}.
\quad}
\]

证明：将积分乘以单位复数 \(e^{-i\gamma\log\sqrt{xy}}\)。其被积项相位位于 \([-\gamma\ell/2,\gamma\ell/2]\)，因此旋转后的实部至少为

\[
\cos(\gamma\ell/2)\int_x^yF(t)t^{\beta-1}\,dt
\ge A y^{\beta-1}\cos(\gamma\ell/2).
\]

右侧非负，且复数模不小于其实部，结论成立。这个引理不要求多项式核、对称核或特定光滑阶数。

它只限制单个 Mellin 变换的模；不能据此限制不同零点贡献之和的相消。旋转相位依赖于 \(\gamma\)，不能对所有零点同时采用不同旋转后再把实部相加。

## 3. 四次幂尺度下的数值

取

\[
L=120,\quad x=e^{120},\quad h=4x^{3/4},\quad
H=3\cdot10^{12},\quad \beta=7/8.
\]

256-bit Arb 给出

\[
\varepsilon=h/x=4e^{-30}
=3.74304918753606984196633288935\ldots\cdot10^{-13},
\]
\[
H\ell=1.12291475626061079633159520276\ldots.
\]

因而 \(\gamma\le2H\) 时相位弧长仍小于 \(\pi\)。下表各项由上面的引理获得，不依赖选用哪一种非负核。

| 高度 | \(\gamma\ell\) | 下界除以 \(x^{-1/8}\) | 单零点归一化变换下界 |
|---|---:|---:|---:|
| \(H\) | 1.12291475626 | 0.846480072375 | \(2.58940218398\cdot10^{-7}\) |
| \(1.01H\) | 1.13414390382 | 0.843477432491 | \(2.58021703890\cdot10^{-7}\) |
| \(2H\) | 2.24582951252 | 0.433057025858 | \(1.32473149119\cdot10^{-7}\) |

**H 这一行只是变换在该参数处的值。** 已知有限 RH 验证排除了高度不超过 H 的右侧零点，并非声称那里存在 \(\beta=7/8\) 的零点。对略高于核验高度的区域，上界所允许的未知零点才是实际估计问题。

相对于常用零阶包络 \(x^{\beta-1}\)，在 \(\gamma=1.01H\) 处，仅改变非负核不能把该单零点模压低到原尺度的 \(84.35\%\) 以下。换言之，该处最多只有约 1.186 倍的改善空间，不是几千倍。

当前多项式核的 `g=min_j R_j(q/t)^j` 在这一高度附近仍是零阶平台 `g=1`。因此，至少在这个低频部分，它与“任意非负核可能达到的最佳模”相差有限因子。较高频处仍可能有较大的核改进空间；这个局部引理不禁止那类改善。

## 4. 旧 v1 输入下的密度规模（历史比较）

在 \(\sigma=7/8\) 处，Chourasiya–Simonič 的最后一个适用子区间给出

\[
D_{CS}(T)=22.44T^{1/3}(\log T)^3
+6.240(\log T)^2+110.7\log T.
\]

它适用于 \(T\ge H\)。[固定 v1，Corollary 1、Table 1](https://arxiv.org/html/2507.15184v1)

FKS 的统一常数给出

\[
D_{FKS}(T)=17.4194T^{1/3}(\log T)^{13/4}
+5.2954(\log T)^2.
\]

若对 \(\sigma\in[.87,.88]\) 使用其 Table 8 第一组对应行，可将两个常数改为 11.0755、3.1321。[固定 v3，Corollary 2.9、Table 8](https://arxiv.org/html/2204.02588v3)

在 \(T=1.01H\) 处，数值为：

| 输入 | 累计右侧零点数的解析上界表达式 |
|---|---:|
| CS 对应行 | \(7.70806944883248\cdot10^9\) |
| FKS 统一常数 | \(1.38540178908072\cdot10^{10}\) |
| FKS 对应区间常数 | \(8.80857961649231\cdot10^9\) |

另一方面，若**假设**有 K 个正高度零点位于 \(H<\gamma\le1.01H\)、\(\beta=7/8\)，那么只计算这些零点及其共轭的绝对值，便至少为

\[
2K\,(2.58021703889990\ldots\cdot10^{-7}).
\]

故要使这种绝对值预算小于 1，必须有

\[
K<1,937,821.479596\ldots.
\]

这里的密度上界比这个比较尺度大约 3978 倍。这个差距在换成 FKS 对应行后仍存在，不能归咎于只选了过大的统一常数。

加入有限 RH 高度之后的总零点数帽也不会自动解决这个例子。用 Rosser 总数上界和下界，可以在 \((H,1.01H]\) 上得到右侧零点帽

\[
\frac{N_{\rm upper}(1.01H)-N_{\rm lower}(H)}2
<6.42112362815\cdot10^{10},
\]

仍大于上述 CS 密度上界。这只是说明该简单局部帽在这个带宽内不占优；不排除更强的局部计数输入。

**不能把 \(D_{CS}(T)\) 乘以单零点变换下界，称作实际误差下界。** 一个是数量上界，另一个是条件于特定零点位置的单项下界，两者不能这样组成对真实零点和的下界。这里的乘积只比较“现有输入未排除的数量尺度”与“非负核无法压低的单项尺度”。更不能断言确有这些零点，或断言这些零点的真实贡献同相。

## 5. 对下一步的实际含义

这些计算支持一个有限的判断：**如果继续使用非负紧支撑核、逐零点绝对值和同一版本的累计密度输入，单靠把现有多项式核换成另一个核，不应被预期为自然消除剩余的数量级缺口。** v1 与 v2 的缺口大小有实质差别，不能混用；v2 的更新尺度见第 7 节。

但它还不是整个框架的下界定理。当前 `delta` 同时包含更高高度、不同实部、分层和包络损失；这里没有解完“所有核和所有合法分层”的最优化问题，也没有构造满足 zeta 的全部已知约束的极端零点分布。仍需把当前积分按高度和实部分解，确认可改进预算具体位于哪些单元。

优先可检查：

- H 以上第一批高度区间的右侧零点计数能否得到远强于当前累计密度的控制。
- 是否存在能严格利用零点之间相消的估计，而不是只改变单项模的包络。
- 更紧的实部上界、更多有限 RH 核验或其它已证明结构，是否能缩小当前未知零点区域。
- 针对高度超过约 \(\pi/\ell=2.79771250317\ldots H\) 的部分比较少数核；此数只是相位引理失去正下界的边界，不是所需 RH 核验高度的充分或必要门槛。

这个诊断不反对继续进行有针对性的核实验；它反对在缺乏误差分解时，把长时间盲目调核当作中段闭合的主要希望。

## 6. 旧 v1 比较的可复算代码（只输出，不生成新文件）

以下代码使用 `python-flint`，常数均由整数构造。它核查相位条件，并输出下界、密度尺度及总数帽的球区间。

```python
from flint import arb, ctx
ctx.prec = 256
q = lambda a, b=1: arb(a) / b
L, H = q(120), q(3 * 10**12)
eps = 4 * (-L / 4).exp()
ell = (1 + eps).log()
weight = (-L / 8 - ell / 8).exp()

def cs(t):
    u = t.log()
    return q(561, 25) * (u / 3).exp() * u**3 + q(156, 25) * u**2 + q(1107, 10) * u

def fks(t, c1, c2):
    u = t.log()
    return c1 * (u / 3).exp() * (q(13, 4) * u.log()).exp() + c2 * u**2

def P(t):
    return t / (2 * arb.pi()) * (t / (2 * arb.pi() * q(1).exp())).log() + q(7, 8)

def R(t):
    u = t.log()
    return q(137, 1000) * u + q(443, 1000) * u.log() + q(1588, 1000)

assert 2 * H * ell < arb.pi()
print('epsilon:', eps)
print('H*ell:', H * ell)
for label, t in [('H', H), ('1.01H', q(101, 100) * H), ('2H', 2 * H)]:
    lower = weight * (t * ell / 2).cos()
    assert lower > 0
    print(label, 'single-transform lower:', lower)
    print(label, 'ratio to x^(-1/8):', (-ell / 8).exp() * (t * ell / 2).cos())
    print(label, 'conjugate-pair count scale:', 1 / (2 * lower))
    print(label, 'CS cumulative upper:', cs(t))
    print(label, 'FKS uniform upper:', fks(t, q(87097, 5000), q(26477, 5000)))
    print(label, 'FKS row upper:', fks(t, q(22151, 2000), q(31321, 10000)))
t = q(101, 100) * H
print('local right-side count cap:', (P(t) + R(t) - P(H) + R(H)) / 2)
```

本次已执行与此相同的 Arb 计算。无需新增探索脚本或将这些尺度比较误登记为中段证书。

## 7. CS v2 更新：改善约一个数量级，仍未闭合

已重新阅读 [CS arXiv:2507.15184v2，Corollary 1 与 Table 1](https://arxiv.org/html/2507.15184v2)。v2 的对数幂是

\[
q(\sigma)=\frac{7-5\sigma}{2-\sigma},
\qquad q(7/8)=7/3,
\]

而非 v1 的统一三次幂。对 \([0.84375,0.875]\) 的对应行，三个常数为 21.77、6.240、110.7。因此在 \(\sigma=7/8\) 处应使用

\[
D_{CS,v2}(T)=21.77\,T^{1/3}(\log T)^{7/3}
+6.240(\log T)^2+110.7\log T.
\]

在同一 \(T=1.01H\) 处，512-bit Arb 给出

\[
D_{CS,v2}(T)
=797012168.5634069986513113497813075\ldots,
\]

旧 v1 表达式与它的比值约为 9.67120673041。相位引理仍给出不变的单项下界 \(2.58021703889990\ldots\cdot10^{-7}\)，因此第 4 节的**尺度比较值**从约 3977.70 降为

\[
2D_{CS,v2}(1.01H)\,(2.58021703889990\ldots\cdot10^{-7})
=411.292875507573\ldots.
\]

这仍然只是数量上界与条件单项下界的尺度比较，**不是实际零点误差下界**。不能把它解释成已证明所有非负核的最终误差上界都大于 411。

当前 `results/smooth_k4_cs2.csv` 在 `k=4,L=120,M=2,density=cs2` 记录

```text
delta          = 2957.5104226909857
density_layers = 2957.5104226905282
```

相比第 1 节旧 v1 主导的 `hybrid` 记录约改善 8.7 倍；素数幂及其余小项基本不变。这是已经读回的探索产物，不是本节新增的严格中段证书。它说明版本更新具有实质效果，然而当前正性判据仍未接近 `delta<1`。后续讨论应以这份 v2 结果为准，并继续分析各高度和实部的贡献，不能沿用“当前仍是 25638”或“当前密度规模仍大四千倍”的说法。

复算本节密度尺度的独立代码：

```python
from flint import arb, ctx
ctx.prec = 512
q = lambda n, d=1: arb(n) / d
L, H = q(120), q(3 * 10**12)
t = q(101, 100) * H
u = t.log()
ell = (1 + 4 * (-L / 4).exp()).log()
lower = (-L / 8 - ell / 8).exp() * (t * ell / 2).cos()
D_v2 = q(2177, 100) * (u / 3 + q(7, 3) * u.log()).exp()
D_v2 += q(156, 25) * u**2 + q(1107, 10) * u
print('CS v2 cumulative upper:', D_v2)
print('Scale comparison, NOT actual error lower:', 2 * lower * D_v2)
```
