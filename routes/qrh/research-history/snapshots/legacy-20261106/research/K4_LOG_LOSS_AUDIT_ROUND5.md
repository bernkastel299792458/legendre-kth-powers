# k4 第五轮：远端主误差与对数损失审计

日期：2026-11-06。等级：解析诊断与研究目标，**不是新的覆盖证书**。

本轮响应用户提出的远端突破方向。既有 `L≥372` 和整数下端证明保持不变。
这里区分三件事：旧预算的渐近形状、密度定理中损失的实际来源、尚待证明的新估计。

## 1. 为什么核常数不是主要突破口

固定 k4 梯形核，`L=log x`、`q=1+exp(L/4)/4`。主要密度项的连续形式为

\[
 B_1(L)=2L\int_{1/2}^{7/8}c(\sigma)e^{-(1-\sigma)L}
 q^{p(\sigma)} I_{p(\sigma),p(\sigma)+2}(q)\,d\sigma,
 \quad p(\sigma)=\frac{3(1-\sigma)}{2-\sigma},
\]

其中 `I` 是固定核导数正测度的对数矩；定义与严格比较见
[第三轮单调比较](K4_MONOTONE_ROUND3.md)。在 `L→∞`、固定核及固定 CS 行常数时，
`I` 的主阶为 `(log q)^(p+2)` 乘有限正核矩。

指数相位

\[
 f(\sigma)=\sigma-1+\frac{p(\sigma)}4
\]

在本区间严格递增。在右端

\[
 p(7/8)=1/3,\qquad f(7/8)=-1/24,\qquad f'(7/8)=11/27>0.
\]

端点 Laplace 宽度是 `O(1/L)`，抵消外面的 `L`。所以旧主预算的渐近形状为

\[
 B_1(L)\sim C L^{7/3}e^{-L/24},\quad C>0.
\]

这不是用于有限 L 认证的替代公式；完整反事实实验保留所有积分与其他误差。
它解释了为何常数除以十只把临界 L 降低几十，而不是消除二百多个单位的缺口。
更换核可以改变 `C`，但在同一密度输入和绝对值分层框架下不能自动改变 `-1/24` 或 `7/3`。
本句不排除使用额外相位信息或不同算术框架的核方法。

## 2. CS 的对数幂有具体来源

固定来源：[Chourasiya–Simonič, arXiv:2507.15184v2](https://arxiv.org/html/2507.15184v2)，
推论1、引理9、式(32)及定理1的证明。

该证明先选 `sigma'=sigma-d/log T`，再通过 Littlewood 引理将横向零点距离
转成零点数。因子 `1/(sigma-sigma')` 贡献一次 `log T`。
在 `h=1` 的主项中，矩插值另外贡献

\[
 \frac{4(1-\sigma)}{2-\sigma}+\frac1{2-\sigma}.
\]

因此总对数幂恰为

\[
 1+\frac{4(1-\sigma)}{2-\sigma}+\frac1{2-\sigma}
 =\frac{7-5\sigma}{2-\sigma}=p(\sigma)+2.
\]

在右端 `sigma=7/8`，分解为 `1+4/9+8/9=7/3`。其中第一项矩插值部分
用到了 ζ 在临界线的四次矩；该四次矩本身有真实的 `T log^4 T` 主阶。
不能通过增加浮点精度，或直接把真实四次矩换成 `O(T)`，来删除这些对数。
可研究的是联合 mollified moment、不同零点检测器及更少损失的加权转换。
这里尚未证明其中任何一项能够达到所需节约。

## 3. 直接使用积分密度不会白省一个对数

令 `b=7/8`、`a=1/2`，固定高度 T，并定义

\[
 B(\sigma,T)=\int_\sigma^b N(u,T)\,du.
\]

有限高度下 N 是有界阶梯函数，故 B 绝对连续，且几乎处处 `B'=-N`。
对每个 `L>0`，分部积分给出精确恒等式

\[
 \int_a^b e^{L\sigma}N(\sigma,T)\,d\sigma
 =e^{La}B(a,T)+L\int_a^b e^{L\sigma}B(\sigma,T)\,d\sigma.
\]

于是，即使绕过 Littlewood 的距离除法得到少一次 `log T` 的 B 上界，
转换回所需的指数加权预算时还要支付 `L`。承重高度满足 `log T≈L/4`，
所以这一步通常只是改变常数，而非自动节省整个对数幂。
它并不排除一个**实质更强**的直接加权矩定理；它排除了“改写成积分密度就已省掉一幂”的论证。

## 4. 新输入必须与目标匹配

反事实删除对数因子只是逆向确定强度，不是推导。尤其不能随意要求

\[
 N(\sigma,T)\le C T^{p(\sigma)}
\]

以固定 C 对全部 `1/2≤sigma≤7/8`、全部大 T 成立：在 `sigma=1/2`，对称性给出
`N(1/2,T)≥N(T)/2`，故与 `N(T)~T log T/(2pi)` 冲突。即使排除该端点，在 `sigma↓1/2` 时保持一致常数，
也会推出右半平面的离线零点数为 `O(T)`；再由对称性得到离线零点密度为零。
这比当前需要强得多，不应成为未经审查的研究前提。

优先考虑混合输入：左侧条带保留 CS，只改进承担主要预算的右侧条带；
新估计也可仅覆盖有限高度盒，其外沿用旧 CS 高尾。
由于 `L≥372` 已经证明，新引理只须帮助补齐一个有限 L 段，
不必先解决一个比任务更强的全高度统一密度问题。

## 5. 两个不能直接替换的外部结果

- 经典 Huxley 指数 `3(1-sigma)/(3sigma-1)` 在适用域更好，但其传统
  `log^44 T` 和未给出的显式常数必须一并计入。只把该指数装进 CS 的常数和
  对数幂，是反事实敏感性分析，不能称为 Huxley 定理的应用。
- [Bellotti 的显式无对数密度界，arXiv:2405.12545v2](https://arxiv.org/html/2405.12545v2)
  定理1.1使用的实部下限在 `.985` 附近或更靠右，超出本项目 QRH 截断 `7/8`。
  因而当前版本不能直接替换这里的承重条带。

这些限制支持收窄新引理的目标，并不构成任何一般不可能性结论。
