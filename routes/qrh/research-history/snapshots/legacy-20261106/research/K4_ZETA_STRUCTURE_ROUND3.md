# 第三轮：真实 ζ 结构、相位矩与 L=120 的定量缺口

2026-11-06。Codex / 子代理 `qrh_status`。状态：解析推导与常数核算；没有证明新的中段含素数定理。只新增本文，不修改 k6 发布稿、旧证书或主文档。数值用 python-flint Arb 256 位在内存核算。

本轮接受 QRH(7/8)，但以下“排除旧模型”甚至不需要 QRH。必须区分三个问题：排除一份不是真实 ζ 的零点模型；控制真实 ζ 的某个零点块；证明所有目标短区间含素数。前两件事本身不等于第三件事。

## 1. 真实非负系数已经排除旧模型，但只给出临界边界

沿用现有 M=2 核：

\[
x=e^L,\quad h=4x^{3/4},\quad \varepsilon=h/x,
\quad \phi(v)=v^2(1-v)^2,\quad I=1/30,
\quad F(t)=\phi((t-x)/h).
\]

记

\[
Z_F=\frac{1}{hI}\sum_\rho\widehat F(\rho),\qquad
\tau_F=\frac1{hI}\int_x^{x+h}\frac{F(t)}{t^3-t}\,dt>0.
\]

共轭配对后 Z_F 为实数。现有合法的平滑显式公式给出

\[
\frac{\sum_m\Lambda(m)F(m)}{hI}=1-Z_F-\tau_F. \tag{1}
\]

由于真实 von Mangoldt 系数非负，立刻有新的、不是累计计数约束的必要条件

\[
\boxed{Z_F\le 1-\tau_F.} \tag{2}
\]

这是所有真实 ζ 零点必须满足的算术相位条件。它立即排除 `STRUCTURAL_ROUND2.md` 的完整 M=2 模型：在 L=120，右侧相干批次及其共轭给出下界 51.1696986618…，临界线背景的总贡献之模小于 10^-10，左侧对称批次实部非负，所以模型违反 (2)。因此不能说旧模型在加入真实显式公式与 Λ≥0 后仍然可行。

不过，(2) 只证明左侧加权 Λ 和非负。若区间内没有素数，左侧仍可由素数幂提供小的非负量。沿用现有安全素数幂界，

\[
P_F\le\frac{15}{8}\frac{\sqrt{x+h}\log^2(x+h)}{2\log2\,h}.
\]

在 L=120，Arb 给出

\[
P_F<4.557\cdot10^{-10},\qquad
0<\tau_F\le\frac1{x^3-x}<10^{-156}.
\]

于是“没有素数”仍允许

\[
1-\tau_F-P_F\le Z_F\le1-\tau_F. \tag{3}
\]

例如新证据若能证明 Z_F≤1−10^-8，就足以突破这一点；本文没有证明该间隙。把 (2) 重命名为“相消定理”而默认有严格间隙，会把待证的算术信息藏起来。等式 (1) 下，最直接的该间隙恰好就是加权素数和下界，必须从额外可计算信息取得。

## 2. 一个精确的、可检验的局部相位矩引理

下面先对旧模型中的同实部块定量，目的不是假定真实 ζ 恰好有这样的块。取

\[
b=8749/10000,\quad H=3\cdot10^{12},\quad W=10^8,
\quad \ell=\log(1+\varepsilon),\quad c=L+\ell/2.
\]

设某块有 K 个正高度零点 b+iγ_j，其中 H≤γ_j≤H+W。令

\[
Q_B(c)=\sum_{j=1}^K e^{i\gamma_jc},\qquad
B(w)=30\int_0^1v^2(1-v)^2\cos(w(v-1/2))\,dv.
\]

取 z=w/2，则可直接积分得到

\[
B(w)=15\frac{(3-z^2)\sin z-3z\cos z}{z^5}.
\]

定义

\[
\Delta=(1-b)\ell+\frac{(H+W)\varepsilon^2}{8}
                  +\frac{W\ell}{2}. \tag{4}
\]

**引理。** 若 B(Hℓ)>0，该块及其共轭对 Z_F 的实部贡献满足

\[
Z_{F,B}\le2e^{(b-1)L}
 \bigl(B(H\ell)|Q_B(c)|+K\Delta\bigr). \tag{5}
\]

证明：将每个 Mellin 变换写成

\[
\frac{\widehat F(b+i\gamma)}{hI}
=e^{(b-1)L}e^{i\gamma c}A_b(\gamma),
\]

其中

\[
A_b(\gamma)=30\int_0^1v^2(1-v)^2(1+\varepsilon v)^{b-1}
 e^{i\gamma(\log(1+\varepsilon v)-\ell/2)}dv.
\]

有 |(1+εv)^(b−1)−1|≤(1−b)ℓ。由二阶导数界，凹函数 log(1+εv) 与端点弦 vℓ 的差在 [0,ε²/8] 内；再用 |e^(iu)−e^(iv)|≤|u−v| 和 |v−1/2|≤1/2，即得 |A_b(γ)−B(Hℓ)|≤Δ。三角不等式仅用于这个受控的小变化，而保留 Q_B 的真实相位，遂得 (5)。

在 L=120、K=10^8：

| 数量 | Arb 256 位核算（显示近似值） |
|---|---:|
| ε | 3.74304918753606984×10^-13 |
| Hℓ | 1.12291475626061080 |
| B(Hℓ) | 0.977679487250855929 |
| Δ | 1.87152460370432078×10^-5 |
| 完全相干的主近似 2K exp((b−1)L) B(Hℓ) | 59.1013956507304 |
| 令 (5) 右侧等于 1 的 Q 阈值 | 1690093.16876742042 |
| 对应 \|Q\|/K | 0.0169009316876742 |
| 对应 \|Q\|²/K² | 0.000285641491911430 |

因此一个简明、保守的有限检验目标是

\[
|Q_B(c)|\le1{,}690{,}000,\quad\text{或等价地}\quad
K+2\sum_{i<j}\cos((\gamma_i-\gamma_j)c)
\le(1{,}690{,}000)^2. \tag{6}
\]

这会使**该块**贡献小于 1。若只分配预算 r<1，右端所需幅度应改成

\[
|Q_B(c)|<\frac{r e^{(1-b)L}/2-K\Delta}{B(H\ell)}. \tag{7}
\]

不得把 (6) 当作全区间证书：其他实部、其他高度、素数幂与平凡零点仍要分配预算；对真实可变 β 的块也必须保留其精确权重，或另加实部变化误差。这里只把“需要相消”变成一个明确的二阶相位矩数值目标。QRH 与累计密度本身没有给出 (6)。

## 3. Euler 乘积给出的新约束接口

对任意 σ>1，绝对收敛的 Euler 乘积对数导数为

\[
A_\sigma(t)=-\frac{\zeta'}{\zeta}(\sigma+it)
=\sum_{n\ge2}\Lambda(n)n^{-\sigma}e^{-it\log n}.
\]

因此任意实 t_j 和复 z_j 都满足

\[
\sum_{j,k}z_j\overline{z_k}A_\sigma(t_j-t_k)
=\sum_{n\ge2}\Lambda(n)n^{-\sigma}
 \left|\sum_jz_je^{-it_j\log n}\right|^2\ge0. \tag{8}
\]

这给出真实 ζ 必须服从的有限正半定矩阵约束，超出零点累计计数。已知有限素数/素数幂的矩阵可从两边扣去，剩余矩阵仍正半定。最小的 2×2 条件仅为 |Aσ(t)|≤Aσ(0)；单靠这个绝对值界并没有建立 (6)。

可检验的后续任务是：选定有限 t_j，把 Hadamard/显式公式代入 (8)，精确界定所有未计算零点和 gamma 项，检查它是否排除“贡献接近 1”的候选分布。必须同时保留非对角项；若又对每项独立取模，新增的相位信息会丢失。本文没有完成该有限矩阵计算，也没有声称任意模型都能扩展为满足 (8) 的 Euler 乘积。

## 4. 两个不能直接替代新引理的候选

### 4.1 Landau–Gonek 相位和：固定 x 的误差不能代入本问题

[Gonek 原文 Theorem 1](https://www.sas.rochester.edu/mth/people/faculty/gonek-steve/assets/pdf/8-landau-form.pdf) 给出对 x,T>1 的一致形式，其中主项是 −TΛ(x)/(2π)，但含 O(x log(2x) log log(3x)) 与 O(x log(2T))，以及近素数幂距离项。不能把固定 x、T→∞ 的 O(log T) 在 x=e^120 的应用中当作常数独立于 x。

除以 x 后，前两项的无隐常数尺度在 L=120、T=H 分别约为 578.9174 与 29.4228；原定理没有给此处可直接认证的数值常数。相减两个截止高度也不能默认这些端点误差相消。这个被核对的一致公式因而**没有提供**所需的小于 1 界；这不是证明任何更精细的 Landau 型论证都不可能。

### 4.2 现有 pair correlation 不是目标频率的有限局部估计

[Montgomery 原文](https://public.websites.umich.edu/~hlm/paircor1.pdf) 的基础定理假定完整 RH，控制频率参数 0≤α<1。这里 log x/log H=4.1768719534…；此外 (6) 是指定高度块、指定实部层的有限相位矩，不等于该全体零点渐近。

值得保留的真实额外结构来自 [Baluyot–Goldston–Suriajaya–Turnage-Butterbaugh, Theorem 1 与 Lemma 3](https://arxiv.org/html/2306.04799v1)。其无条件复零点版本可以写成非负 L² 积分，且 α∈[0,1] 有渐近；出版信息见 [Acta Arith. 214 (2024), 357–376](https://doi.org/10.4064/aa230612-20-3)。它避免了偷偷假定 RH，但仍不直接给 α≈4.177、有限高度与选定高 β 子块的 (6)。删掉其他零点来获得子块上界也不合法：L² 正性不意味着每个子块的 L² 小于总和的 L²。

因此本轮没有用任何 pair-correlation 猜想、随机相位或未显式化的 O 常数填补缺口。低频矩能否另行排除旧模型的过规则排列，仍可研究；本次未声称该排除已经证明。

## 5. 可复算的纯常数核算

以下代码仅计算已推导表达式，不读取或证实任何实际高零点。执行 `python -B`，不会生成缓存或证书文件。

```python
from flint import arb, ctx
ctx.prec = 256
L, b = arb(120), arb(8749)/10000
H, W, K = arb(3)*10**12, arb(10)**8, arb(10)**8
eps = 4*(-L/4).exp()
ell = eps.log1p()
z = H*ell/2
B = 15*((3-z*z)*z.sin()-3*z*z.cos())/z**5
D = (1-b)*ell + (H+W)*eps**2/8 + W*ell/2
Q = (((1-b)*L).exp()/2-K*D)/B
pp = arb(15)/8*(L+ell)**2*(ell/2-L/4).exp()/(8*arb(2).log())
assert B > 0
assert Q > 1690093
assert pp < arb('4.557e-10')
print('B', B.str(45))
print('Delta', D.str(45))
print('Q threshold', Q.str(45))
print('Epp', pp.str(45))
```

本文的可用产出是 (2)、(5)–(8) 及其精确适用边界。排除原模型已有真实算术理由；能否在所有目标 L 上证明足够的严格余量，仍是未解决的数学任务。
