# 第五轮：重新计算高高度密度常数，远段推进至 log x ≥ 362

2026-11-06。Codex 主对话理论研究。旧证书、k6、传统路线和计算分支均保持原样。

## 结论及准确前提

在 QRH(7/8)、[Chourasiya–Simonič arXiv:2507.15184v2](https://arxiv.org/html/2507.15184v2)
的 Theorem 1、Corollary 5 和 Table 1 第一行，以及有限高度 RH 和经典显式公式等输入下，
对所有实数 `x ≥ exp(362)`，开区间 `(x,x+4x^(3/4))` 含素数。
于是所有整数 `n ≥ exp(181/2)` 均满足相邻四次幂之间有素数。

CS v2 仍是明确接受的预印本前提。本项目没有重证它的上游引理。
这项新推论使用的 CS 前提比旧模块的“Corollary 1 指定表行”更广，不能隐去这个变化。
特别是本轮重新使用 [Platt–Trudgian 有限 RH](https://arxiv.org/abs/2004.09765)，
不能沿用旧远段的“不需要有限 RH”标签。

下端理论覆盖仍为 `n ≤ 1904041788883`，因此理论缺口变为
`113.1 < 4 log n < 362`。这是书面条件证明与数值认证，不是全范围 k4 或端到端 Lean。

## 1. 为什么可以改变密度起算高度

CS Theorem 1 的 `H,H0` 与 `T0` 是不同参数。固定

```
H = H0 = 3000000000000, T0 = exp(80), A0 = exp(75),
h = 1, d = 3/10, kappa = 3/20, delta = 1/5.
```

对于 `T ≥ T0`，保留有限 RH 给出的 `N(sigma,H)=0`，同时用更大的 T0
重新计算定理中的常数。没有把有限 RH 高度提高到 exp(80)，也没有把 T 换成 T−H。

定理涉及的高度、delta、h 和 A0 条件直接满足。
对 sigma 的第一行 `[1/2,17/32]`，保留旧 Table 1 的 `(5.069,9.461,167.8)`。
其他十一行使用 Theorem 1，因为其最小左端点满足
`17/32 > 1/2 + (3/10)/80 ≥ 1/2 + d/log T`。
每行仍为闭区间 `[i/32,(i+1)/32]`，i=17,...,27。

## 2. 不使用浮点求积计算 K1

CS 的 K2、K3 积分通过 Gamma(3/2)=sqrt(pi)/2 直接计算。
唯一剩余积分是式 (37) 的 K1。记 `U=log T0`、`a=3/(4 kappa)`，
`v=2/(3U)`，并置

\[
c=\frac{va}{1+a},\qquad D=\exp\{v[\log(1+a)-a/(1+a)]\},\qquad r=1-c>0.
\]

两次对数切线给出，对 u≥0，

\[
\left(1+\frac{\log(1+au)}{2U}\right)^{4/3}
\le (1+au)^v\le D e^{cu}.
\]

再由正数的次可加性 `(X+Y)^(2/3) ≤ X^(2/3)+Y^(2/3)`，有

\[
\int_0^\infty e^{-u}u^{1/6}
 \left(1+\frac{\log(1+au)}{2U}\right)^{4/3}
 (C_1\sqrt{au}+C_2)^{2/3}\,du
\le D\left[
 (C_1\sqrt a)^{2/3}\frac{\Gamma(3/2)}{r^{3/2}}
 +C_2^{2/3}\frac{\Gamma(7/6)}{r^{7/6}}\right].
\]

乘以式 (37) 的外部因子，并完整加入其有限 A0 项，得到 K1 的严格上界。
这包括整个积分尾部，没有数值截断，也没有求积误差估计问题。
其余 C1–C6、L0、L1、L2、A1–A5 按源公式计算；具体逐项映射在脚本注释及审阅中。
有 `K3>1,L0>1`，所以公式中这两者的负指数最大值均等于 1。
保留 K1 的所有正指数最大值，因此用 K1 上界代替精确值是单调且合法的。

256 位 Arb 的关键标量为 `K1 ≤ 1.613264`、`K2 < 2.496740`、`K3 < 6.318518`。
这些显示小数只作说明，证书始终使用完整球及向上取整的有理行常数。

## 3. 形成新的十二行密度界

写 `p(sigma)=3(1−sigma)/(2−sigma)`。由于 h=1，Theorem 1 的两个主项
对数幂之差是 `6(1−sigma)/(2−sigma)`，该差随 sigma 递减。
于是每行右端点 t 给出合法合并系数

\[
B_1=\frac{A_1+A_2\,80^{-6(1-t)/(2-t)}}{2\pi d},\qquad
B_2=A_3+A_4,\qquad B_3=A_3\log H+A_5.
\]

从而对 T≥exp(80)，各行满足

\[
N(\sigma,T)\le B_1T^{p(\sigma)}(\log T)^{p(\sigma)+2}
             +B_2(\log T)^2+B_3\log T.
\]

常数逐项向上舍入至小数点后十二位。完整表在
[证书](rebased_density_certificate.json) 的 `rows` 字段；末行系数为
`(15.342550439191,5.771186642313,102.342751492480)`，旧首列为21.77。
没有声称所有新行都优于旧行；第一条重算行的新 B1 甚至稍大，仍完整计入预算。
本轮不把别的密度界、sigma 行插值或随机相消作为输入。

## 4. 一点到整个无穷段

保持旧梯形核 `a=1/8,b=7/8`，`R1=16/7,R2=256/7`。
令 `q(L)=1+exp(L/4)/4`。在 L0=362，核的非平坦部分从

\[
u_0=\log(R_1q(362))=89.9403842120645\ldots>80
\]

开始。因此每次调用新表都在 T≥exp(80) 内；这也是不能把重算表直接用于整个旧中段的原因。
累计密度已经包含 H 到 exp(80) 之间的零点，不会漏掉这段零点的剩余核权重。

密度的高度和对数指数没有改变。故
[第三轮的固定正测度比较](../research/K4_MONOTONE_ROUND3.md)
逐项适用：主项衰减率为
`1/24−3/(4u0)−1/362 > 0`，其余密度项、基底及素数幂亦有正衰减率。
所有比较对象都是精确连续预算，不是声称数值离散包络随 L 单调。

使用原已冻结梯形积分器、sigma 步长1/65536，仅在内存替换表常数，得到

\[
\Delta(362)\le
\frac{996211053335085260769876}{10^{24}}
<0.997<1.
\]

积分器使用正上和的 sigma 权重、解析高度切线和完整无限尾部；
完整零点、正素数幂及平凡零点均计入。
以上正衰减率证明所有 L≥362 都有 Delta(L)<1。
最后的加权素数抽取和严格端点与
[原梯形显式公式](../research/K4_ROUND3_CERTIFICATE.md) 相同。
