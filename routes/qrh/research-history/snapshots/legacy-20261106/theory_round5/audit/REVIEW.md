## 2. 零点对称性：可以恢复一个项，但收益极小

设 A_L(T) 为所有正高度零点的 `exp((beta-1)L)` 之和。利用 beta 与 1-beta 的配对，
在 QRH(7/8) 下有精确恒等式（sigma 端点的计数约定不影响积分）

\[
A_L(T)=e^{-L/2}N(T)+L\int_{1/2}^{7/8}
 \big(e^{(\sigma-1)L}-e^{-\sigma L}\big)N(\sigma,T)\,d\sigma.
\]

因此旧预算可以保留负的第二指数。旧推导丢弃它是合法上界，并非漏计问题。
但对于旧 CS 表，该改进不能有效推进 L=372：令 g 为旧梯形高度包络，则被删除预算 S 满足

\[
0\le S(L)\le 2e^{-L/2}\int_0^\infty
 [21.77T(\log T)^3+9.461(\log T)^2+167.8\log T]\,(-dg(T)).
\]

这个上界使用旧表的最大系数及 p≤1、p+2≤3；仅在非平坦高度高于 H 的范围使用。
独立解析高度上界给出

```
S(120) < 2.869e-7,
S(372) < 3.374e-33.
```

这些是旧密度上界表达式能节省量的上界，不是把未知实际零点分布替代为一个猜想模型。
没有理由将这项恢复作为本轮远段突破的主要来源。

## 3. 谱 L1 与 Gaussian：真实可改进处及固定族的限制

对 round4 的 Selberg 函数，`||f||1≤2d+2pi/K` 及
`||G0||1≤2K(2d+2pi/K)` 均合法，前者不要求区间内 f 处处非负。
后一条明显丢失频谱形状；由 [Lê–Vaaler 的 Fourier 公式与 Lemma 3.1](https://arxiv.org/pdf/1309.1506v1)
可将其替换为显式一维积分。置

\[
W(u)=\pi u(1-u)\cot(\pi u)+u\quad(0<u<1),\quad W(0)=1,\ W(1)=0.
\]

在 0<t<K 时，直接转换 Fourier 归一化得到

\[
G_0(t)=\frac{2\sin(dt)}t W(t/K)
       -\frac{2\pi}{K}\cos(dt)(1-t/K).
\]

故精确的谱 L1 可以写成

\[
\|G_0\|_1=4\int_0^1
 \left|\frac{\sin(Kdu)}u W(u)-\pi\cos(Kdu)(1-u)\right|du.
\]

这只是解析表达式，本次未为该积分生成新的严格求积证书。
原 round4 的无穷位界约 159.7，素数幂界约 9227.2；单独缩小前者对原预算的
效果有限。频谱在边缘消失也可能有助于跨越 H 的窄谱带，但不在本次已验证范围内。

Gaussian 卷积在复零点处有真实泄漏；原文保留该尾部正确。
质量损失 `2d^3` 可严格缩为 `2d^3/3`，不过在现有参数下不具实质量级。
下面还能给出关于**同一个固定 Selberg 函数、K=H-128、固定 Gaussian**的负结果，
以免误认为大幅提升来自忽略负尾的某个符号：

令 `F_eta(v)=f(v)e^(-eta v^2)`，eta≥1/8，记 `m=2d-2pi/K`。则

\[
G_\eta(i/2)\le m+\frac{32\eta d^3}{3}+\frac{128\sqrt\eta}{K^2}.
\tag{A}
\]

证明：`w_eta=e^(-eta v^2)cosh(v/2)` 满足 0<w_eta≤1，
`1-w_eta≤min(eta v^2,1)`。Beurling 误差界给出
`0≤chi-f≤K_B(tau(v+d))+K_B(tau(v-d))=:E(v)`。
所以 `G_eta(i/2)-m≤integral E(v)(1-w_eta(v))dv`。
在 |v|≤2d 使用 E≤2，得到 32eta d^3/3；在 |v|>2d 使用
`E(v)≤32/(K^2 v^2)`，并将非负积分扩展至整个实轴，得到
`32/K^2 * integral min(eta,1/v^2)dv=128sqrt(eta)/K^2`。证毕。

特别地，在 L=120、eta=1 时，独立 Arb 给出

```
m < -1.7200901837290e-12,
Gaussian possible compensation < 1.422223e-23,
G_1(i/2) < -1.7200901837147e-12 < 0.
```

所以仅仅精确计算这一固定族的 Gaussian 负尾补偿，无法使 L=120 的 pole 项转正。
式 (A) 没有排除改变频宽、很大的 eta、不同 minorant 或更有效的未知零点处理。
它也不否定本轮其他子任务正在研究的极窄频谱边缘外推。

## 4. 两项可用的后续改进，尚未纳入冻结主链

**更紧的 K1。** 设 a、c、D 与主证明一致，r=1-c，X=C1 sqrt(a)。
对 u>0，用凹性切线
`(X sqrt(u)+C2)^(2/3)≤X^(2/3)u^(1/3)+(2/3)C2 X^(-1/3)u^(-1/6)`，
乘以 u^(1/6) 后奇异性完全消失。于是原 K1 积分上界中的

\[
C_2^{2/3}\Gamma(7/6)r^{-7/6}
\]

可替换为

\[
\frac{2C_2}{3X^{1/3}r}.
\]

独立计算给出 K1 上界从 `1.6132639547658520...` 降为 `1.5142934550939328...`。
这个改进是可复算的解析上界，但本轮没有据此重算全表或宣称新的 L 起点。

**更紧的远段衰减率。** 无需分别最大化 p+2 与 sigma-1+p/4。
当 u0>16/11 时，函数
`sigma-1+p(sigma)/4+(p(sigma)+2)/(4u0)` 在 [1/2,7/8] 递增。
在右端取最大值，得到

\[
\eta_{1,\mathrm{sharp}}=\frac1{24}-\frac7{12u_0}-\frac1{L_0}.
\]

在 L0=362，它为 `0.0324184580821287...`，比现用率更好。
这加强已通过起点之后的下降速度，不会自动认证一个更小的新起点。
