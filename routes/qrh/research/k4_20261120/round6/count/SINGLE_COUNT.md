# 一个矩形中的必要零点数

令 \(H=3000175332800\)，\(T_*=H\exp(37/4)\)。在项目 QRH(7/8)、所列已验证高度与解析输入下，任何一个四次幂反例都会迫使
\[
 \#\{\rho=\beta+i\gamma:\ .814<\beta\le7/8,\quad H<\gamma\le T_*\}
 \ \ge\ 1\,050\,001 .
\]
这里只计正虚部，按 ζ 的零点重数计。200 位区间计算给出
\(31\,215\,521\,411\,322\,038<T_*<31\,215\,521\,411\,322\,039\)。
该必要条件仍容许存在反例。若能证明该矩形的实际计数至多 1,050,000，就能闭合两端。

设该计数为 \(N_*\)。若 \(N_*\le C\)，则在每个 \(.814\le s\le7/8\)、\(H\le t\le T_*\) 上均有 \(N_{>s}(t)\le C\)，因为高度 \(H\) 以下已验证 RH。写 \(A_s(t)=\sum_{H<\gamma\le t}(\beta-s)_+\)，在这一区域取相邻节点 \(s<s'\) 便得到 \(A_s(t)\le A_{s'}(t)+(s'-s)C\)。对其余实部、高度及所有无穷尾仍采用[已证的全高度界与显式公式](../reduction/IRREGULAR.md)。在 \(s=7/8\) 正部为零；对全部实部节点从右向左累计并逐点取已有正部矩的较小上界。沿用[模 30 的临界线估计](../folds/FOLD_MEAN.md)，其余实部弦与零点总数的基项一同计入。

按物理区间步长 \(1/8\)、对数高度步长 \(1/16\)，在整个 \([115.035950,155]\) 上的归一化总扣除小于 .994851（\(C=970000\)）。此时最吃紧的一格始于 \(L=116.285950\)。取 \(C=800000\) 则全段费用小于 .986731。该区间与已证[低端](../../round5/low/NARROW_COVER.md)和[远端](../folds/BRIDGE.md)均相接。计数为整数，取逆否命题即得所列下界。此处额外采用一条统一约束。它覆盖原来九个框中全部实部和高度；本文的阈值由完整显式公式重新核验。

在同一矩形上，单用上述模 30 的硬截断四阶矩，把物理网格和对数高度网格分别改成 \(1/80\) 和 \(1/64\)，取 \(C=1000000\) 也能覆盖至 155，费用小于 .999189。再改用[第四谐波的左边界矩](../phase/SMOOTH_PHASE.md)和物理、对数高度步长 \(1/32\)。若 \(C=1050000\)，则在 \([115.035950,150]\) 上的总归一化扣除小于 .981281；最吃紧的格始于 \(116.348450\)。该段右端衔接[模 2310 检测器证明的半直线](../folds/MODULUS_2310.md)。这是所述 1,050,001 的来源。

~~~sh
python -B round6/count/single_count.py --cap 1050000 --phased --nheight 32 --cell 1/32 --last 150
python -B round6/count/single_count.py --cap 1000000 --nheight 64 --cell 1/80
python -B round6/count/single_count.py --cap 970000
python -B round6/count/single_count.py --known-only
~~~

同一矩形的现成正部矩在 \(s=.802\) 给出 \(N_{>.814}(T_*)<17\,842\,016\,712\)，其中已使用模 30 临界线改进。计算方法为用 \(A_s(T_*)/(.814-s)\) 上界计数，在已有实部节点中择优。这个上界与排除反例所需的上界之间还有四个数量级。九框路线对各个实部和高度分别计数，容许的数目随位置改变。[九框坐标及其阈值](../reduction/IRREGULAR.md)
