# 零点检测函数的逐点常数下限

设 \(1<\nu\le2\)，整函数 \(D(0)=1\)，在 \(-1\) 的零点重数至少为 \(m\ge1\)。若对一切复数 \(z\) 有 \(\log |D(z)|\le m C |z|^\nu\)，则
\[
 C\ \ge\
 \frac{2^\nu(\nu-1)^{\nu-1}}{2\nu^\nu I_\nu},\qquad
 I_\nu=\frac{2^{\nu-2}\Gamma((\nu-1)/2)}
                  {\sqrt\pi\,\Gamma(\nu/2)} .
\]
这是对检测函数本身的约束，允许次数无限增大，也允许按矩指数分别设计检测函数。

**证明。** 在圆盘 \(|z+a|<R\) 取 \(a>1/2,\ R>a\)。点 \(0,-1\) 都在内部。边界点 \(z=-a+R e^{i\theta}\) 对 \(0\) 的调和测度为 \((R^2-a^2)|z|^{-2}d\theta/(2\pi)\)。圆盘 Green 函数在这两点之间的值为 \(\log[(R^2-a(a-1))/R]\)。Poisson–Jensen 公式中其余零点贡献非负，故
\[
 C(R^2-a^2)\int_{-\pi}^\pi|-a+Re^{i\theta}|^{\nu-2}
                    \frac{d\theta}{2\pi}
 \ \ge\ \log\frac{R^2-a(a-1)}R .
\]
可取边界无零点的半径列下降到 \(a\)。因模长的平方至少为 \(4a^2\sin^2(\theta/2)\)，且 \(\nu>1\)，控制收敛与 beta 积分给出左侧积分趋于 \(a^{\nu-2}I_\nu\)。右侧对 \(R\) 求导后在 \(a\) 的值为 \(2-1/a\)。因此 \(C\ge(2a-1)/(2a^\nu I_\nu)\)。在 \(a=\nu/[2(\nu-1)]\) 处取极大即得。

在第一轮远端上界中，只替换逐点检测常数，固定两边矩界、插值放宽、弦系数与高度矩放宽。所有乘数为正，故用上式替换得到的是**该预算表达式**可达到数值的下限。允许每个高度及每个实部各自挑选检测函数也适用。在 \(L=280,295,300\)，仅矩项就分别至少为 \(2.0210,1.2173,1.0269\)。因此即使其余边界损失为零，这个特定策略也无法到达 \(300\)。ζ 的真实零点之和没有由此得到下界。主攻路线随后改变了边界矩和频谱权，不受这个数值障碍约束。[第一轮预算](../../upper/PROOF.md) · [192 位区间核验](check_floor.py)
