# 光滑化显式公式（研究笔记）

*2026-11-06。目标：用光滑权代替 Cully-Hugill–Johnston 的尖锐截断显式公式，缩小 k = 67 的缺口。*

## 1. 推导

设 φ: ℝ → [0,1] 支撑在 [0,1] 上，φ ∈ C^{M−1}，φ^{(i)}(0) = φ^{(i)}(1) = 0（i ≤ M−1），M ≥ 2。
取 F(t) = φ((t−x)/h)，h = k x^{1−1/k}，ε = h/x。记 F̂(s) = ∫ F(t) t^{s−1} dt。

**显式公式。** 对 F ∈ C^1、紧支于 (1, ∞)：
Σ_n Λ(n) F(n) = ∫F − Σ_ρ F̂(ρ) − ∫ F(t) dt/(t³ − t)。

推导：由 ψ0(t) = t − Σ_ρ t^ρ/ρ − log 2π − ½ log(1 − t^{−2})，以及 Σ Λ(n)F(n) = −∫ F'(t) ψ(t) dt，
截断显式公式在紧集上有界，并且在非素数幂点收敛，于是可以用控制收敛定理交换求和与积分。
另外 −∫ F' t^ρ/ρ = F̂(ρ)，−∫ F'·t = ∫F，½∫ F' log(1−t^{−2}) = −∫ F/(t³−t)。
（这是经典结论；正式写作时应引用 Ingham 或 Cully-Hugill–Lee 2022 的对应引理。）

**单个零点的估计。** 设 ρ = β + iγ。
- 直接估计：|F̂(ρ)| ≤ ∫ F t^{β−1} ≤ x^{β−1} h ∫φ。
- 分部积分 j 次（j ≤ M，没有边界项）：
  F̂(ρ) = (−1)^j ∫ F^{(j)}(t) t^{ρ+j−1} dt / (ρ(ρ+1)⋯(ρ+j−1))。
  由 ∫|F^{(j)}| = h^{1−j}‖φ^{(j)}‖_1、|ρ+i| ≥ |γ| 和 (x+h)^{β+j−1} ≤ x^{β−1} x^j (1+ε)^j，得到

  |F̂(ρ)| / (h∫φ) ≤ x^{β−1} · g(|γ|)，　g(t) := min_{0≤j≤M} R_j (1+ε)^j (x/(h t))^j，　R_j := ‖φ^{(j)}‖_1 / ∫φ。

**零点求和。**
- |γ| ≤ H_R 的零点满足 β = ½，贡献至多 2N(H_R) x^{−1/2}。
- 对 |γ| > H_R，令 Φ(t) ≥ Σ_{H_R<γ≤t} x^{β−1}，这个上界和命题 H 一样，由平凡估计、KLN 和 Bellotti 拼接得到，
  只是把高度 2T 换成 t。由于 Φ(H_R) = 0 且 gΦ → 0（M ≥ 2），用 Stieltjes 分部积分得到
  Σ_{|γ|>H_R} x^{β−1} g(|γ|) ≤ 2 ∫_{H_R}^∞ Φ(t) (−g'(t)) dt。

**结论。** 令
δ_s = 2∫_{H_R}^∞ Φ(t)(−dg) + 2N(H_R) x^{−1/2} + (max φ/∫φ)·(E_pp + 1/(x³−x))，
若 δ_s < 1，则 Σ_{x<p<x+h} log p · φ((p−x)/h) > 0，从而 (x, x+h) 中有素数。

**与尖锐截断的对比。**
- 尖锐截断：高度 2T = x^{c/k} 以下的零点都按权 1 计入，另外还有截断误差项。
- 光滑化：g ≈ 1 只在 t ≲ (x/h)·R_j^{1/j} 时成立，再往上按 (x/(ht))^j 衰减，而且没有截断误差。
- 有效高度从 u = cL/k（c ≈ 1.05–1.2）降到约 log(x/h) + O(1) = L/k − log k + O(1)，降低约 log k ≈ 4.2。

## 2. 权函数

φ_M(y) = y^M (1−y)^M。数值上有：

| M | R_1 | R_2 | R_M | max φ/∫φ |
|---|---|---|---|---|
| 2 | 3.75 | 23.1 | 23.1 | 1.875 |

## 4. 严格结果（`code/rigorous_smooth.py`、`code/close_gap.py`）

1. **只用 Lee 那部分 Bellotti 表（log T ≥ 80）**：k = 67 的严格缺口从 (2040.63, 6989.94) 缩到
   **(2343.80, 5535.30)**。下端用 M = 3、2，上端用 M = 3、8、12，证书已移到 `results/superseded/`。
   上端停在 5535 处时 δ 从约 0.59 直接跳过 1：再往下，需要控制的零点高度掉到 e^80 以下，
   那里在这部分表里没有 log-free 估计。
2. **加入 Bellotti Table 2 中 log T < 80 的 22 行**（Lee 没有引用）：k = 67 的缺口**完全闭合**。
   1241 段证书覆盖 [2040.63, 6989.94]，max δ = 0.937，见 `docs/k67_theorem.md`。
   - 只把博士论文中的 Littlewood 常数 19.62 换进来、其余用 4.896/53.989 时，同样闭合（max δ = 0.9998）；
   - 只用已发表常数（4.896/21.233/53.989）时闭合不了：L ∈ [~3900, ~6800] 上 δ 最高约 1.53。
3. k = 66、65 闭合不了，严格覆盖分别停在 L ≈ 3361.5 和 2050.0。浮点估计：k = 64 时最大 δ ≈ 1.77。
