## 1. 记号与问题归约

- L = log x，h = k x^{1−1/k}，ε = h/x = k e^{−L/k}。
- 参数 μ ∈ (1/k, 1/10)，取 2T = x^μ，u = log(2T) = μL。（这里用 μ，不和 Chebyshev 函数 θ 混用。）
- N(T)、N(σ,T) 是通常的零点计数函数（0 < γ < T，β > σ）。
- Lee §4 的归约：对 n ≥ 2 有 (n+1)^k − n^k ≥ k n^{k−1}。所以只要 (3.2) 对 x = n^k 成立，
  就有素数 p ∈ (n^k, n^k + k n^{k−1}] ⊂ (n^k, (n+1)^k)。k ≥ 65 时只需考虑 x ≥ 2^k > 3.68×10^19。
- 区间分工（以 k = 67 为例）：
  - L ≤ L_low(k) = k log(kΔ(1−Δ^{-1})^2)，Δ = 2.51949×10^11：Lee Prop 3.3（Cully-Hugill–Lee 区间估计）；
  - L ∈ [L0(k), xA(k)]：本文的定理 A 证书；
  - L ≥ xA(k)：Lee Prop 3.2（只用 KLN 估计）。

## 2. 命题 H（拼接版的 Lee Prop 3.1）

**命题 H.** 设 k ≥ 11，x ≥ e^1000，μ ∈ (1/k, 1/10)，2T = x^μ。假设：

- (H1) T ≥ H_R = 3 000 175 332 800，且 max{51, log x} < 2T < (x^{1/10} − 2)/4；
- (H2) η > 0，且 ζ(σ+it) ≠ 0 对 σ ≥ 1 − η、|t| ≤ 2T 成立；
- (H3) 0.6 < σ1 ≤ σ* < 1，σ* ≥ 0.985；Bellotti 表中有一行 (T0, T1, C, B) 满足 log T0 ≤ u ≤ log T1；
- (H4) λ_K := L(1 − 8μ/3) − 2 log u ≥ 1，λ_B := L(1 − Bμ) ≥ 1。

那么 |θ(x+h) − θ(x) − h| ≤ δ·h，其中 δ = E_triv + E_K + E_B + E_tr + E_pp：

- E_triv = (u/π) · e^{−(1−σ1−μ)L}
- E_K = 2·17.253 · u³ · (L/λ_K) · e^{−(1−σ*)λ_K} + 2·5.663 · u² · e^{−(1−σ*)L}
- E_B = 2C · (L/λ_B) · e^{−η λ_B}
- E_tr = (2·1.26/k) · [(1+ε)(L+ε)^{4/5} + L^{4/5}] · e^{−(μ−1/k)L}
- E_pp = k^{−1}(α1 √(1+ε) − 0.999) e^{−(1/2−1/k)L} + k^{−1}(α2 (1+ε)^{1/3} − 0.885) e^{−(2/3−1/k)L}，
  其中 α1 = 1 + 1.93378×10^{-8}，α2 = 1 + 1.936×10^{-8}。

特别地，δ < 1 ⇒ θ(x+h) − θ(x) > 0。

Lee 的 Prop 3.1 有两种用法：σ* = 1 − η，即全部用 KLN；或 σ1 = σ* = 0.985，即全部用 Bellotti，
β < 0.985 的零点只用平凡估计。命题 H 是把两者拼起来的版本。

### 证明

1. **显式公式**（Cully-Hugill–Johnston II，即 Lee (3.3)）：在 (H1) 下，存在 T* ∈ [T, 2T]，使得
   |ψ(x+h) − ψ(x) − h + Σ(T*)| ≤ 1.26 [(x+h)(log(x+h))^{4/5} + x(log x)^{4/5}]/T，
   其中 Σ(T*) = Σ_{|γ|≤T*} ((x+h)^ρ − x^ρ)/ρ。
   两边除以 h，利用 1/T = 2x^{−μ} 和 log(x+h) ≤ L + ε，就得到 E_tr。
2. **ψ → θ**（Lee (3.4)，log x ≥ 300）：ψ − θ 单调不减，因此
   0 ≤ (ψ−θ)(x+h) − (ψ−θ)(x) ≤ α1 (x+h)^{1/2} + α2 (x+h)^{1/3} − 0.999 x^{1/2} − 0.885 x^{1/3}，
   除以 h 得到 E_pp。
3. **零点和：** |((x+h)^ρ − x^ρ)/ρ| = |∫_x^{x+h} t^{ρ−1} dt| ≤ h x^{β−1}。零点关于实轴对称，所以
   |Σ(T*)|/h ≤ 2 Σ_{0<γ≤2T} x^{β−1}。
   用 x^{β−1} = x^{−1} + ∫_0^β x^{σ−1} L dσ 逐项展开并求和；在 [0, σ1] 上用 N(σ,2T) ≤ N(2T)，
   再由 (H2) 得到 σ > 1 − η 时 N(σ,2T) = 0，于是
   Σ_{0<γ≤2T} x^{β−1} ≤ N(2T) x^{σ1−1} + ∫_{σ1}^{1−η} N(σ,2T) x^{σ−1} L dσ。
   由 Lee (2.5)，N(2T) ≤ 2T log(2T)/(2π) = x^μ u/(2π)，第一项乘 2 之后就是 E_triv。
4. **拆分积分（本文的改动）：** 把 ∫_{σ1}^{1−η} 拆成 ∫_{σ1}^{σ*} + ∫_{σ*}^{1−η}。
   被积函数非负，所以当 σ* ≥ 1−η 时，用 ∫_{σ1}^{σ*} 代替全部积分仍是上界。
   - 在 [σ1, σ*] 上用 KLN/Johnston–Yang 估计（Lee (2.7)，要求 0.6 < σ < 1，2T ≥ H_R）：
     N(σ,2T) ≤ 17.253 u³ (e^{8u/3} u²)^{1−σ} + 5.663 u²。
     积分 ∫_{σ1}^{σ*} e^{−(1−σ)λ_K} L dσ ≤ (L/λ_K) e^{−(1−σ*)λ_K}，
     ∫_{σ1}^{σ*} e^{(σ−1)L} L dσ ≤ e^{−(1−σ*)L}，乘 2 得到 E_K。
   - 在 [σ*, 1−η] 上用 Bellotti 估计（Lee (2.6)，要求 σ > σ0 = 0.985，T0 ≤ 2T ≤ T1）：
     N(σ,2T) ≤ C e^{Bu(1−σ)}，于是 ∫_{σ*}^{1−η} C e^{−(1−σ)λ_B} L dσ ≤ C (L/λ_B) e^{−ηλ_B}，乘 2 得到 E_B。
5. 把以上各项相加即得结论。∎

两种密度估计是同一个量 N(σ,2T) 在不同 σ 范围上的上界，所以分段使用是合法的。

## 3. 严格的数值验证

对每一段 L ∈ I = [a, b]（端点是精确的有理数），固定参数 μ = c/k、σ*、σ1 = 27/40（c、σ* 也是精确有理数），
然后用 **arb 球算术**（python-flint 0.9.0，160 位精度）计算：

- 把 L 当作覆盖整个 I 的球，u 当作覆盖 μI 的球。这样每一步运算都包含 I 上的取值范围，
  得到的 δ 上界对 I 中**每一个** L 同时成立，不需要网格或单调性假设。
- η 取 η_low = max{1/(Z1 U), log U/(Z2 U), 1/(Z3 U^{2/3}(log U)^{1/3})} 的严格下界，其中 U = μb 是 I 上 u 的最大值，
  Z1 = 4.862，Z2 = 19.62，Z3 = 51.34（Yang，经 Lee (2.1)–(2.2)）。
  理由：这三种零点自由区域对 t ≥ 3 都成立，宽度函数在 log t > e 时都单调递减，
  所以对所有 |t| ≤ e^U，零点自由宽度至少是 η_low，从而 (H2) 对 I 中每个 L 都成立。
  这里没有使用 Lee 代码里的 Ford 区域；去掉它只会让结论更保守，而且在本文涉及的范围内它从来不是最优的那一项。
- 在 arb 中逐条**确定性地**检查 (H1)–(H4)（"certainly" 比较）：μ ∈ (1/k, 1/10)、a ≥ 1000、
  T ≥ H_R（即 u ≥ log 2H_R）、整个 u 段落在 Bellotti 的同一行内、2T 的上下界、λ_K, λ_B ≥ 1。
- 覆盖算法：从 xA(k) 往下逐段推进，用 float 版本挑参数，再用 arb 验证；验证失败就把段宽减半，
  减到 1/64 仍失败就停止。停下的位置就是 L0(k)。
- **证书：** `results/cert_hyb_k{k}.csv` 列出每一段的 (a, b, c, σ*) 和 δ 上界。
  `code/check_certificate.py` 会独立地重算每一段，并检查各段首尾相接、恰好覆盖 [L0, xA]。
  21 份证书全部通过复核。
