# Withdrawn: k = 67 certificates (v3)

These certificates prove (3.2) for k = 67 **conditional on the Littlewood constant 19.62** from Yang's PhD thesis.
They are numerically valid as conditional certificates.

The independent audit (`../../zfr_audit/`) found an arithmetic error in the thesis proof of 19.62 (Lemma 3.8, p. 59). With the repaired estimate of about 19.90–20.08, k = 67 does not close. The k = 67 claim is therefore **withdrawn**.

The current results are:
- k = 70 (4.896 + 21.233);
- k = 74 (all inputs refereed).
