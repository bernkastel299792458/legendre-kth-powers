## 1. 4.896（BTY）——已核实

详细报告：[`bty_4.896/REPORT.md`](bty_4.896/REPORT.md)。

**复算方法**
- 从 arXiv 下载 LaTeX 源文件（PDF 提取的文本丢了希腊字母），逐条检查 §3–§5 的全部推理。
- 用 python-flint（arb 球算术，200 bit）复算全部数值条件。精确的有理数部分用 Fraction 和 Sturm 序列处理。
- Lemma 14 的左边，用 `acb.integral` 严格求积直接计算后对照。

**发现的问题（按影响大小排序）**
1. **Lemma 14 有符号错误。** (41) 中 η² 项的系数应为 4.64，论文写成 ≥ 11。此外，Ford 界被用在 x₁ < tan θ 的情形（m = 1, 2），而那里该界不适用。改用合法的估计后，η³ 系数从 3897 降到 568；η² 系数从 26 降到 20.15。直接求积表明，论文给出的不等式本身在网格上仍然成立。
2. **Table 1 的 m₅ = 0.00735709 不是下界。** 在 x = 1.6495 处，G₅(1, x) = 0.0073564919，这是 arb 严格计算的点值。换成经过认证的 0.00735649 之后，Σ log p·m_p = 0.2354513，仍然大于 0.23545。
3. **Lemma 8 的使用超出了其假设。** 它被用在高度 kt（k ≤ 16）上，但假设 η ≤ A₀/log(kt) 并不成立。修正后，(48) 中 η³ 的系数从 8013 变为 8396。
4. **Lemma 8 的 (32) 陈述错误。** ∫U/(x₀²+y²)^{3/2} 的值是 34.58，不小于 24。不过证明真正需要的、以 |Re ψ| 为被积函数的积分是 23.60 < 24，所以结论不受影响。
5. **笔误和陈述错误，均无影响：**
   - 参数表中 A₀ 印成 (4.8596)⁻¹，应为 (4.896)⁻¹；
   - Lemma 4 中 Ford 的 c₀ 少了一个 sec θ（论文推出的数值用的是正确的 c₀）；
   - Lemma 5 在 Im z = T 上的理由写错了（真正需要的符号是 Σ m b_m = 1/859 > 0）；
   - "f(0)" 实际表示的是 ηw(0)；
   - 其余若干处算术或引用笔误。

**最后一步的余量**（修正后的常数；严格计算，用 4000 个 L 球覆盖整个区间）

| log t 的范围 | 论文的收尾路线 | 耦合路线（见报告 §4） |
|---|---|---|
| [log H, 55.01] | 9.2·10⁻³（0.90%） | 1.7% |
| [log H, 76.47] | 4.7·10⁻⁴（0.05%）；用论文原数字只有 6·10⁻⁵ | 0.64% |

**上游依赖**（详表见报告 §5）：
- 已评审：Platt–Trudgian 2021、Heath-Brown 1992、Ford 2002（以 arXiv v4 的修正常数为准）、Kadiri 2005、Lehman 1966、Mossinghoff–Trudgian 2015、Yang JMAA 2024（21.233）；
- **不依赖**博士论文。

- **致命问题（F1，引理 3.8）。** 第 59 页有 log C₃ < 1.66 − 4.27λ\*，代入后应得

## 3. 需求曲线

详细报告：[`requirement/REPORT.md`](requirement/REPORT.md)。计算由子任务 B 完成；主线程用 `spot_check.py` 独立复核，并补做了全格点的高度剖面和 Z₁/Z₂ 交换的测试。

**方法**

- 然后重新搜索覆盖：Prop S 的块宽 ≥ 1/256，M ≤ 4；Prop H 重新优化 c 和 σ\*；S/H 的交界可以移动。
- 找到的覆盖整体用 arb 严格重算，并检查连续性。

| 常数 | 按证书原参数 | 重新优化后可容忍 | 瓶颈 |

## 5. 能否收紧

- **4.896。**
  - 用修正后的常数，并把 η 与 A 耦合起来，同一方法在 t ≤ e^55.01 上大约可以给出 4.81–4.85，在 t ≤ e^76.47 上约为 4.86–4.89。这些是指示性数值：η₀、σ₀ 依赖于 A₀，相应的常数没有重算。
  - 对 BTY 自己的定理没有必要。对 k = 67 却可能有用：如果 Littlewood 常数只能做到统一的 19.90，k = 67 需要 Z₁ ≤ 4.835（直到 e^61.3）。耦合路线约给出 4.830，论文路线只给出 4.867（路线 (c)，见 `requirement/REPORT.md` §4b）。
- **19.62。** 方向相反：论文的方法修好之后，常数会变大到约 19.90–20.08。要让 k = 67 闭合，需要以下之一：
  - 统一常数 ≤ 19.85；
  - 随高度变化的版本（路线 (b)）；
  - 配合更强的经典常数（路线 (c)）。
  - 从局部常数看，路线 (b) 最有希望：瓶颈高度 log t ≈ 58–85 上，局部常数只有 19.3–20.0；决定统一常数的最大值出现在 log t ≈ 95–129，而那里 k = 67 的要求宽松得多（≥ 20.9）。
