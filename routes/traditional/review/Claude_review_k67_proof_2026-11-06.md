## 3. 逐项核查（成立的部分）

### 3.1 归约与下段：Lemma 1、2、6（成立）

- **Lemma 1**：k ≥ 67 时 67·n^{k(1−1/67)} ≤ k·n^{k−1}，并且 n^k + k·n^{k−1} + 1 ≤ (n+1)^k。另外 2⁶⁷ > 4·10¹⁸。三点都成立。
- **Lemma 6**：(x+h)(1 − 1/Δ) ≥ x 等价于 h(Δ−1) ≥ x，再等价于 67x^{−1/67}(Δ−1) ≥ 1。推导成立。两个数值事实的余量分别为 2.6·10⁹ 和 3.8·10⁸（Arb 复跑）。
- **Lean**：我用现有构建重跑了 `Audit.lean`，所有定理只依赖 `propext`、`Classical.choice`、`Quot.sound`。源码中没有 `sorry`、`axiom`、`native_decide`。
- **Lean 的范围**：`Hypotheses` 的字段与 §10 一致，常数 L₁、L₂、L₃、Δ₁ = 39097000、Δ₂ = 251949000000 与证书和 CHL 一致。

### 3.2 命题 H（成立）

逐项重新推导了 E_triv、E_K、E_B、E_tr、E_pp：

- **单个零点**：|((x+h)^ρ − x^ρ)/ρ| ≤ h·x^{β−1}，再乘 2 计入共轭零点。
- **改写零点和**：x^{β−1} = x^{−1} + ∫₀^β x^{σ−1}L dσ。σ ≤ σ₁ 的部分合计 N(2T)·x^{σ₁−1}，用 (I2) 放大后正好是 E_triv。
- **KLN 段**：在 [σ₁, σ\*] 上用 (I3)，并有 ∫ e^{−(1−σ)λ} dσ ≤ e^{−(1−σ\*)λ}/λ。σ\* ≥ 1 − η 时把积分区间延长，结论仍是上界。
- **Bellotti 段**：在 [σ\*, 1−η] 上用 (I4)。高度 2T 必须落在同一行内，代码检查了这一点。
- **截断误差 E_tr**：由 (I6) 得到，其中用了 log(x+h) ≤ L + ε。
- **E_pp**：用 (I7) 的上界与下界。
- **(I6) 原文核对**：CHJ II 的 Theorem 1.3 和 Corollary 3.3 确实给出 x 与 x+h 共用同一个 T\* ∈ [T, 2T]。原文在推论后专门说明，分别对 x 和 x+h 套用推论不够。T 的条件 max{51, log²x} < T < (x^{1/10} − 2)/4 与手稿一致。M = 1.260（α = 1/10，ω = 0.2，log x_M = 10³）在 arXiv v1、v2、v3 中相同。

### 3.3 命题 S、Lemma 3–5（成立）

- **Lemma 3**：
  - 对 j ≤ M 次分部积分没有边界项，因为 i < M 时 φ^{(i)}(0) = φ^{(i)}(1) = 0。
  - |ρ(ρ+1)⋯(ρ+j−1)| ≥ |γ|^j。
  - j ≥ 1 时 β + j − 1 > 0，所以 t^{β+j−1} ≤ (x+h)^{β+j−1} ≤ x^{β−1}x^j(1+ε)^j。
  - 由此得到 g(t) 的形式。
- **Lemma 4（光滑显式公式）**：
  - 平凡零点项 Σ_m F̂(−2m) = ∫F/(t³−t)，以及 log 2π 项消失，这两点我都推过。
  - 用截断显式公式的余项界（部分和在 (1,∞) 的紧集上一致有界）加上有界收敛定理，交换求和与积分是合理的。
  - 陈述有一处问题，见 M4。
- **命题 S**：
  - Stieltjes 分部积分的边界项为零：Φ₀(H_R) = 0，并且 M ≥ 2 时 g(t)N(t) → 0。
  - H_R 以下的零点给出 2N(H_R)x^{−1/2}。

- **Lemma 5**：
  - 三种零点自由宽度在 t > e^e 时都递减，因此高度不超过 t 的零点都满足 β ≤ 1 − η(t)。

## 5. 次要问题

1. **积分起点**：`rigorous_smooth.py` 在 vstart = `LOG_HR.upper()` 时，积分起点比 log H_R 高一个球半径（约 10⁻³⁷），漏掉一段贡献约 10⁻²⁴ 的区间。数值上没有影响，但严格性上应改为从不大于 log H_R 的格点开始。

4. **"此前最好"的措辞**：见第 1 节，应改为"已发表的最好结果是 90，预印本的最好结果是 86"。
5. **文档错误**：`tail.py` 的说明引用了手稿中不存在的"附录 D"。
6. **Lean 的范围**：Lean 只形式化了记账部分。命题 S、H、Lemma T 和全部解析输入都以 `Hypotheses` 的字段进入。手稿如实说明了这一点，但对外宣传时不应让读者把"Lean 无 sorry"理解为核心论证已被机器验证。
7. **命题 H 的最低几段**：δ 达到 0.999999，按严格证书仍然成立。但建议让命题 S 与命题 H 在 L₂ 附近重叠一段：命题 S 在 L ≈ 6990 处 δ ≈ 0.30，余量很大，这样可以提高稳健性。
