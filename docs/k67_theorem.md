# 相邻 67 次方之间总有素数

*2026-11-06，AI4Math / legendre_k67。状态：计算机辅助证明，已严格验证（arb 球算术 + 可复核的证书），**尚未经过人工同行审阅**。*

## 主定理

**定理.** 对每个整数 k ≥ 67 和每个整数 n ≥ 1，区间 (n^k, (n+1)^k) 中至少有一个素数。

此前已知的最好结果是 k ≥ 86（Lee 2026，arXiv:2602.14340）。

**依赖的输入（详见 §4）。** 与 Lee 的 k = 86 定理所用的输入相同，另外加上 Bellotti 密度估计表中 Lee 没有使用的那些行。
特别地，本定理依赖 **Yang 博士论文（UNSW 2025）中的显式 Littlewood 零点自由区域常数 19.62**
（Bellotti–Trudgian–Yang, arXiv:2603.21490 引用并确认了这一结果）。
- 如果只用已正式发表的常数 21.233，本方法在 L ∈ [~3900, ~6800] 上 δ > 1，闭合不了。
- 在新覆盖的窗口里，其余零点自由区域常数可以全部换成不依赖博士论文的版本：经典常数 4.896（arXiv:2603.21490 Thm 1）、KV 常数 53.989（Bellotti 2024），证书依然成立。

## 1. 归约

记 L = log x。只要对所有 x ≥ 4×10^18 证明

　　(3.2)₆₇　θ(x + 67 x^{1−1/67}) − θ(x) > 0，

就能得到主定理：
- n = 1 是平凡情形。
- 对 n ≥ 2、k ≥ 67，取 x = n^k ≥ 2^67 > 4×10^18。由于 (n+1)^k − n^k ≥ k n^{k−1} ≥ 67 x^{1−1/67}，
  (3.2)₆₇ 给出一个素数 p ∈ (x, x + 67x^{1−1/67}] ⊂ (n^k, (n+1)^k)。
  这里 (n+1)^k 是合数，所以右端点不会恰好是那个素数。

## 3. 新的数学要素

### 3.1 命题 H：拼接密度估计
见 `docs/HYB_theorem.md` §2。在 Lee 的 Prop 3.1 中，把 σ 积分拆开：
σ ∈ [0.675, σ*] 用 KLN 估计，σ ∈ [σ*, 1−η] 用 Bellotti 的 log-free 估计。

### 3.2 命题 S：光滑化（推导见 `docs/smoothing.md` §1）
取权 φ_M(y) = y^M (1−y)^M，F(t) = φ_M((t−x)/h)，h = 67 x^{1−1/67}，ε = h/x。则

δ_s := 2∫_{H_R}^∞ Φ(t)(−dg̃(t)) + 2N(H_R) x^{−1/2} + (max φ/∫φ)(E_pp + 1/(x³ − x)) < 1
⇒ Σ_{x<p<x+h} log p · φ((p−x)/h) > 0。

其中：
- g̃(t) = min{1, min_{1≤j≤M} R̃_j (1+ε)^j (x/(h t))^j}，R̃_j ≥ ‖φ^{(j)}‖₁/∫φ（严格上界）；
- Φ(t) 是 Σ_{H_R<γ≤t} x^{β−1} 的上界，按 σ 分段：β < 0.675 的部分用平凡估计 N(t)x^{−0.325}，
  [0.675, σ*] 用 KLN，[σ*, 1−η(t)] 用 Bellotti 表中包含 t 的那一行，并要求 σ* ≥ 该行的 σ0；
- η(t) 是已知零点自由区域在高度 t 处的宽度（单调递减）。

与尖锐截断相比，光滑化有两点好处：没有截断误差项；需要控制的零点有效高度从 x^{c/k} 降到约 (x/h)·O(1)，
log 尺度上降低约 log k。

### 3.3 Bellotti 表中 log T < 80 的行
Bellotti (2024/2025) 的 Table 2 从 T0 = 3×10^12 开始，按 e^29、e^30、…、e^80 分段，
例如 σ0 = 0.9927，C = 37341.72，B = 14.160。Lee 只引用了 log T ≥ 80 的行。

在 Lee 的单一估计框架里，这些行用不上：β < σ0 的零点只能做平凡估计，这要求 θ < 1 − σ0 ≈ 0.007，也就是 k ≳ 140。
命题 H 和命题 S 的拼接让 [σ1, σ0] 这一段改由 KLN 估计处理，这些行才变得可用。

**三个要素缺一不可：**
- 只有 HYB：缺口是 (2040.6, 6989.9)；
- HYB + 光滑化，只用 Lee 那部分表：缺口是 (2343.8, 5535.3)；
- 三者合用：缺口闭合。

## 5. 严格计算是怎么做的

- **球算术：** python-flint 0.9.0（arb），128–160 位精度。对每一段 L ∈ [a, b]，把 L 当作一个球，
  所得上界对段内所有 x 同时成立。
- **v 方向的积分（命题 S）：** 把 v = log t 切成格子，每格上的 S_i 是 Φ 在格子上的严格上界。
  然后用 Abel 求和 ∫Φ(−dg̃) ≤ Σ_i (S'_i − S'_{i−1}) ĝ_i，其中 S' 是 S 的累计最大值，ĝ_i 是 g̃ 在格点处的上界。
  这样所有系数都非负，避免了球与球相减带来的依赖误差。
- **跨行格子：** 如果一个格子跨过 Bellotti 表的分界，就对与它相交的每一行分别求界，取最大值。
  格子里每个 v 至少被其中一行覆盖，所以这个最大值是有效的。
- **尾部：** v ≥ V 时用 Φ ≤ N(t) 和 g̃ = Ã_M t^{−M}，可以显式积分。V 的取法保证 j = M 这一项已经是最小项，并且尾部可以忽略。
- **R̃_j：** φ^{(j)} 是整系数多项式。在 4096 个小格的中点做精确的泰勒展开，得到 ∫|φ^{(j)}| 的严格上界。
- **浮点累加：** 每一项都是非负的上界，累加后整体乘以 (1 + 10^{-12}) 吸收舍入误差。
- **复核：**

  ```bash
  python check_smooth_chain.py --zfr thesis ../results/cert_smooth_full_k67_thesis.csv
  python check_smooth_chain.py --zfr littlewood_thesis ../results/cert_smooth_full_k67_littlewood_thesis.csv
  python check_certificate.py ../results/cert_hyb_k67.csv
  ```
  三项复核全部通过。

## 6. 尚需人工复核的地方（按重要性排序）

1. **Yang 博士论文中的 Littlewood 常数 19.62 尚未正式发表。** 如果它不成立，本定理就不成立
   （只用 21.233 时缺口闭合不了）。Lee 的 k = 86 定理同样依赖这批常数。
2. **命题 S 的光滑显式公式**是经典结论，但正式写作时应给出精确的引用或完整证明，
   包括对 C^1、紧支撑 F 的绝对收敛性与控制收敛的论证。
3. **Lee 的 Prop 3.2 和 Prop 3.3** 是直接引用的。Lee 自己的代码只在阈值点上做了检查，并且有精度设置的 bug
   （`mpm.dps` 应为 `mpm.mp.dps`）。我们的浮点抽查支持他的结论，但没有严格重做。
4. **代码层面**：开发过程中发现并修复了三个 bug（KLN 模式漏算一段积分；Fraction 约分后分子与分母不匹配；
   尾部截断点 V 取得太小），详见 LOG.md。最好有人用另一套实现独立复算。
5. **k = 66、65 用本方法闭合不了**：严格覆盖分别停在 L ≈ 3361.5 和 L ≈ 2050。所以 67 是本方法在现有输入下的极限。
