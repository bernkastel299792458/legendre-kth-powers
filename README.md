# Primes between consecutive integer powers

English · [简体中文](README.zh-CN.md)

## Route A · Assuming QRH(7/8)

The conditional fourth-power manuscript studies the existence of a prime in $(n^4,(n+1)^4)$ for each positive integer $n$, under QRH(7/8) and auxiliary analytic estimates. There are 44,721 explicit prime witnesses in the lower range. With $L=4\log n$, 682 numerical cells connect to the infinite tail starting at $L=167.8$. The numerical certificate can be replayed. The full analytic argument remains provisional.
